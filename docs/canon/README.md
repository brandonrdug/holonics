dated provenance it carries in its own header. Its readings, owner addresses, counts and capability
claims hold at that date. The September 24 reset kept all 45 files whole; only their links were
repaired, with deleted guides and retired code now pointing to history at
[`13f8c734`](https://github.com/brandonrdug/holonics/tree/13f8c734). The prose is unchanged.

Read a canon passage through them. Where the two differ, the objects govern and the canon is the
older spelling. [CLAUDE.md](../../CLAUDE.md) and [AGENTS.md](../../AGENTS.md) list the retired
phrasings (section "The elementary objects"). The canon still uses them, for example:
