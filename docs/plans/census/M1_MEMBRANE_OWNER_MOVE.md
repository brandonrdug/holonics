# M1 live membrane owner move

The current `soma-membrane` package owned the live receiver, constituent, standing and carrier runtime. Its R2 audit found production callers in `life`, including the CPU machine and CUDA execution adapter. The complete live module cluster now lives in `holonics::membrane`, with each life source and example importing that owner directly. The old Cargo package and source exports are removed, with no forwarding alias. The concrete `SparseStandingSurface` and `LiveCurrentMachine` remain runtime representations; they do not replace the general future-sufficient standing law in the Holon/restriction operators and Lean foundation.

The source move retains `LiveCurrentRestImage`, its layout version and its native encode/decode methods. It also retains all tests with the owner. The old package's direct dependencies on `body` and `soma-abi` become direct main-library dependencies for now. Those portable host/device substrate packages are still consumed by the detached `no_std` CUDA kernel. Folding them or `holonic-words` into the final small shared kernel-law leaf is a separate cut; moving `body` alone into main before reversing the ABI/words graph would create a Cargo dependency cycle.

Owner gate: `cargo check -p holonics --lib` passed and the moved `membrane::` library tests passed 56/56. The locked workspace all-target caller gate passed; its command and the focused `life` rest/remount return are recorded in `docs/VERIFICATION_RECEIPTS.tsv`. The R2 audit remains the detailed source/consumer map and records the already retired ERST and replay wrappers.
