## Interoperability contract

[definition] Safetensors is a tensor storage format; a runnable model additionally needs its
operator architecture, configuration and codecs. ONNX can carry an executable operator graph;
a file using custom Holonics operators requires their implementation and is not automatically
executable in an ordinary ONNX runtime. A Burn-like framework interface is a packaging precedent,
not permission to substitute a classical backend for the native operation.

[definition] Soulkiller separates intake, model-realization recovery, excitation/intervention,
family quotient and productive native return. Transformer, diffusion and SSM names describe
foreign/application charts; support is recorded independently for each realized pathway.
An adapter recognizing tensor shapes is not evidence that it executes an architecture.

[definition] Athena export has three distinct targets: native persistence, reversible package
storage inside a standard container, and lowering into standard executable architectures.
The latter requires an explicit target graph/operator map, numeric projection with its defect,
state/chronology mapping, and comparison in the actual target runtime. Exact, projected and
refused outcomes remain explicit; unsupported conversion is not presented as a working export.

[open] Portable recompilation of the current cultivated full native operator, persistent overlay
checkpoints for that owner, and general diffusion/SSM recovery require their actual source owners
and runtime returns. This consolidation specifies and exposes these boundaries; it does not
manufacture adapters, checkpoints or frontier-quality claims from existing package exports.
