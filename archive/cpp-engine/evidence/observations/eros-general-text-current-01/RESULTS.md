## Question

Can ordinary text chronology cultivate one reusable Eros body through the direct live-current
machine, without a host recurrence table, authored prediction rule, fixed n-gram context, or
dataset-sized active cut?

## Receiving law

The tokenizer is a source-world chart. Soma neither contains nor invents it. Each token occurrence
crosses with its exact chart identity and material face.

One complete source line is one source event. For an ordered line

```text
x_0, x_1, ..., x_n
```

the event supplies the co-present oriented causal sections

```text
x_0 -> x_1
x_1 -> x_2
...
x_(n-1) -> x_n
```

The consequence occurrence is the receiver of each section. Neighboring sections share the actual
middle occurrence. The ordered interface is the exact pair of source chart identities; no hash,
synthetic observer, vocabulary table, context-window cap, suffix powerset, recurrence count, or
learned successor is stored outside the live machine. Higher context can arise only by composition
of these co-present sections in Standing across genuinely later source events.

## Qualitative probe reading

Each probe forks the same exact rest body, presents one complete candidate sequence, and reads the
formed constituent and complete successor body.

- A previously unseen ordered pair remains a local grain-2 face with one oriented incidence.
- A recurrent ordered pair reconnects into the already-grown grain-1012 region and its multi-scale
  family of support sections.
- Recurrent alternatives sharing the same immediate antecedent enter the same broad region while
  changing its internal support-section distribution and exact successor body.
- Two probes hold the same final ordered pair fixed while changing an earlier occurrence. Their
  final constituents have the same broad grain and cell extent but different incidence/support
  structure and different successor rest images. Co-present earlier context therefore changes the
  formed topology; the machine is not only consulting the final pair.
- All sixteen actual/sibling branches produce distinct exact successor bodies. This is branch
  discrimination, not a scalar score and not a claim that one branch is universally correct.

All reported probe boundaries remain `OPEN`: this source supplies occurrence chronology but no
world consequence that selects, enacts, or returns a linguistic response. The measured capability
is a durable receiver-relative relational ecology over ordinary text and a lawful basis for later
world action. It is not yet a dialogue policy or text generator.

## Rejected constructions

Three intermediate forms were stopped before being mistaken for results:

1. one event per token consequence serialized a source utterance into false instants;
2. pre-enumerating every suffix support family caused combinatorial growth;
3. detached synthetic receivers and independently matched token boundaries collapsed unrelated
   text into a global mass and produced explosive path growth.

The retained form uses the source line as the event grain and its actual occurrences as the shared
causal complex.
