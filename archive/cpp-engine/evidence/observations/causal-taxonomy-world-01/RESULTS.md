## What was built

`life boundary code-workshop-causal-taxonomy-observe` reads complete mathematical-deed journals
and their real CUDA edge receipts. It refuses a non-CUDA edge, an inexact inverse, an incomplete
candidate/receipt pair, a changed question inside one observation, or an emitted consequence
surface which differs from its receipt.

Every complete native recurrent path becomes one history. Its six carried roles are:

```text
before -> meeting -> deed -> consequence -> return -> after
```

Those roles are written as typed presentation events and one exact `TransitionReceipt` per
history. A history which leaves an inapplicable, incompatible, untransported, or refused
consequence retains that consequence as a typed residual. The resulting presentation and Holon
population are written in the allocation-free ABI and strictly reopened from disk.

The receiver's class law is deliberately smaller than the lifecycle it preserves:

```text
same admitted later question
+ byte-identical complete ordered objective-consequence vector
= one situated causal class at that objective grain.
```

Source filename, material role, flattened path bytes, path depth, recurrence, observer wording,
and class support do not define a class. They remain exact provenance. The class population is a
listener quotient after conduct and never enters Soma or selects a path.
