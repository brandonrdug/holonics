# Circuit atlas 01

Exact receiver-side causal-volume readings of the already-measured changed/prior periplus
factorial from `circuit-navigation-02`. Both siblings are read by the same Rust instrument. The
source periplus receipts remain the authority; the atlas receipts are generated observer surfaces
and enter neither Soma nor the circuit world.

Run from `src/soma`:

```text
cargo run -p life -- boundary circuit-atlas observations/circuit-navigation-02/results/periplus-changed/periplus.json observations/circuit-atlas-01/results/changed.atlas.json
cargo run -p life -- boundary circuit-atlas observations/circuit-navigation-02/results/periplus-prior/periplus.json observations/circuit-atlas-01/results/prior.atlas.json
```
