This observation asks for actual inscription rather than another mark on supplied text.  The
world contains a visible bank of the 95 printable ASCII glyphs and an initially empty output
surface.  Each glyph is a literal key face.  A native completed contact on a key depresses that
key; all keys completed at one gaze event stamp together at one tape position.  Simultaneous keys
overprint instead of being silently ordered or crowned.  The exact event×key multiplicity field
stands beside the human tape render, so no contact is lost in the projection.

The apparatus knows only its own material relation: a key bearing `A` stamps the same `A` shape.
It contains no target string, candidate ranking, semantic state translation, answer key, or
post-machine selection.  That is the operative boundary of an authored decoder.  A renderer,
keyboard, typebar, compiler, or other declared world transducer is not prohibited merely because
humans built it.

Four branches begin from the same measured conversation-workshop body.  Three receive substantial
conversation/theory, Rust, and mathematics histories before the identical keyboard passage; the
fourth exactly repeats the conversation branch.  The produced visual world then returns through
the unchanged eye, after which the identical keyboard passes a second time.  The questions are:

- what glyph configurations are actually stamped;
- whether different histories produce different inscriptions;
- whether the returned inscription changes the next inscription;
- whether the repeated branch is exact through both cycles; and
- what temporal, singleton, chordal, and recurrent structure is present without deleting any
  nonconforming output.

`build_world.py` constructs the three exact contexts and the keyboard.  `read_inscription.py`
transports native CUT contacts through the typewriter world and builds the returned surface.
`run_cuda.sh` conducts context and first inscription; `run_return_cuda.sh` conducts visible return
and second inscription.  `analyze.py` gates repeatability and reports the complete descriptive
read.  Raw radiation wires remain beside every rendered surface.

The measured whole-key coupling actuates all 95 glyphs and turns 124 of 129 positions into large
simultaneous chords.  That is actual production on the empty field, but it is a saturated output
world.  WORKSHOP 02 derives one physical stem per rigid key from this result; it does not discard
or rank Soma's radiation.  Exact measurements are in `RESULTS.md`.
