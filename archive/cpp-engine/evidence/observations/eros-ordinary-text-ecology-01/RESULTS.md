## Meaning

This is not a next-token scalar benchmark. It is a developed local text topology:

```text
exact source grain
  -> simultaneous chronological suffix receivers
  -> recurrent local consequence populations
  -> complete COPY/FOUND path alternatives
  -> actual later residual
  -> changed successor field
```

The immediate open relation is cross-context transport. Exact recurrent suffixes do not yet relate
nonidentical contexts through a shared constituent, paraphrase, consequence, or world effect. The
physical rest is exact but also repeats context material; a scale carrier should share that causal
DAG rather than enlarge this bounded map.
