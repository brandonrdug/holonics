Every Tier-0 (fluent) moment shared **exactly three conditions**. Stated as a conjunction, because the

the form looked deep because the vocabulary was shallow enough that any frame already held it.

Every fluent engine **stored a global accumulating recurrence-curvature field that was never re-zeroed** —

the form** (the gravity, the held lattice) — the fluent engines kept the form, which is *correct* by the
axiom-pair. Their *sin* was not keeping a form; it was keeping it **as a von-Neumann store read back by a
coordinate** (the address, the lookup — the contaminant). *The form was right; the lookup was the crime.*

### Condition (c) — AN INDEPENDENT SECOND STRAND (the current's partner)

Every fluent voice used the **double-helix**: strand A emits, anchored toward an *independent* strand B (the
query / a reference coil) that does not emit. The conserved crossing `Lk` between them carries the
