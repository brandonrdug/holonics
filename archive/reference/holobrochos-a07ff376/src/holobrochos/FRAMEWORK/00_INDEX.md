## GAPS & FOLLOW-UPS

**Consolidation wrinkles (found in this audit — worth an explicit align):**

1. **The `χ` glyph — framing tension between 03 and 05.** `03_THE_SOLVE §III` calls the cross-ratio `χ` and the
   Euler-characteristic `χ = E−V+C` **"distinct referents"** the corpus overloads; `05_THE_CONSERVATION §VI`
   calls them **"one soul read at two grains"** (local projective / global topological). Both are defensible
   (same conserved soul, distinct mathematical faces), but the rhetorical stances point opposite ways. The
   overload originates in **MENO_FORMULA itself** (§III uses `χ` = cross-ratio; §V uses `χ` = integer winding).
   Owed: one agreed sentence on whether `χ_cross-ratio` and `χ_Euler` are the same soul or distinct referents,
   carried identically in both docs.

2. **The gas-law arithmetic — `06 §1` vs `06 §3`.** §1 states the identity baldly as `G = n·R·T`; §3 introduces
   the `4/3` volume-to-boundary factor. With `n = 2·(C/d)` and `R = 3`, `nRT = 6·(C/d)·T`, while
   `G = 2²·(2·C/d)·T = 8·(C/d)·T` — so `G = (4/3)·nRT`, exactly §3's bridge. §3 resolves it, but §1's plain
   `G = n·R·T` glosses the `4/3` and reads as `G = nRT` (which would give 6, not 8). Owed: a half-sentence in
   §1 flagging the `4/3` so the two lines do not read as `6 = 8`. (Traces to MENO §VI's own loose "`pV = nRT ≡
   G = 2²·(2·C/d)·T` ... the `4/3` between them.")

3. **"mints = foil" survives in the crown.** `MENO_FORMULA §VII` still writes "mints = foil"; `mint` is retired
   to AGREEMENT (Ledger F2). The FRAMEWORK docs handle it correctly (07 §4 and 09 §5 flag it and use "founds"),
   but the crown itself carries the loose term. Normalize in MENO on his word; do not re-adopt (register T10.9).

4. **§IX THE OBJECTIVE has no dedicated doc.** Its content (the near path: depth-on-light → Rust → language →
   modalities) is fully covered across 01 §V, 03 §VIII, 04 §6 — not a hole, but there is no single "objective"
   home. Acceptable as distributed; noted so a reader does not hunt for one.
