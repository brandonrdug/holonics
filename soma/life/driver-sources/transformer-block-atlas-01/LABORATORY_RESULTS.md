## Question and stopping condition

Can one pretrained transformer block be read as a situated relational construction rather than as
one opaque vector space: exact source spans become tokenizer addresses and embeddings, chronology
changes query/key placement, attention transports values, branch returns alter the continuing
carrier, and distinct internal substitutions may or may not cross the exposed vocabulary boundary?

The observation selected one already-declared equal-extent sibling relation: the same operations
manual occurs before or after the same conversation current. It stopped after exact native capture
of both 253-token currents and five layer-0 interventions over their 204-token chronological
alignment: query, key, value, query+key, and query+key+value. There was no output agreement gate,
similarity threshold, prompt repair, training, or rerun.

The supported eager attention path was declared so the attention quotient itself could be
observed. The unobserved and observed eight-token emissions were exact for both native currents.
This result therefore grades that fixed eager executor cut, not every possible OLMo runtime.

## 1. The tokenizer is a covering chart, not a vocabulary conjured from nothing

Both rendered chat currents contain 1,060 UTF-8 octets and tokenize to 253 categorical address
occurrences. Each token retains its exact rendered character/octet interval and its incidence with
the source-declared prompt, informant, and current-inscription regions.

The chronological token-address alignment contains 204 occurrences. Of those, 115 change position
and 89 remain at the same position. The moved population is the relocated informant face: 114
aligned occurrences intersect the manual itself and one intersects its adjacent prompt boundary.
The alignment is testimony about this declared sibling relation; it does not identify token IDs
with meanings or whole constructions.

- installed embedding row and block input;

## 3. The changed key field reaches receivers whose own placement did not move

Those same 83 vectors remain exact through head mixture, output projection, attention return,

continually re-expressed. At block output 182,577 of 417,792 aligned BF16 words remain exact. This
is a changing relational sheet, not a static feature coordinate or a scalar activation score.

## 4. The attention quotient is deterministic and receiver-relative

The final prompt occurrence was held as one declared receiver. Its exact maximal source set
remained the same in 11 of 16 heads, but only two heads retained both that source and its exact
normalized BF16 quotient. Five heads selected a different maximal source. Every maximum was unique
except target head 13, where positions 225 and 239 shared one BF16 quotient; the compact leader
artifact records the earlier tied position.

For the 11 stable source positions, the final query, selected key, and their unscaled exact dyadic
pairing remained exact. The normalized quotient could still change because the other eligible keys
changed. For example:

- head 0 retained source position 251 and the same exact query-key pairing while its quotient
  changed from `109/512` to `59/256`;
- head 10 retained the same source and pairing while its quotient changed from `129/256` to `1/2`;
  and
- head 2 changed its strongest source from a comma in the current inscription to another comma in
  the fixed prompt, despite both occurrences carrying token address 11.

This is a precise bounded face of the project's probability interpretation. The quotient is not
chance, truth, importance, or a property stored in either endpoint. It is the deterministic
receiver-relative normalization of one pairing within the co-present field. Attention is not by
itself an explanation of the model; this result states only the exact relation measured here.

The installed model computes rotary phase and softmax through its inherited finite numerical
implementation. The observer did not replace that implementation with ideal real arithmetic. It
decoded every retained BF16 word as an exact dyadic and computed the reported unscaled Q-K pairings
with integer/dyadic operations; no cosine, norm, PCA, or floating similarity entered the evidence.

## 5. Query, key, and value are causally distinct—not three detachable features

Every intervention replaced all 204 aligned vectors at its named post-rotary face with the source
current's exact vectors while leaving unmatched target material, chronology, cache, and all other
faces in place.

| Imported face | Layer-0 interior versus target | Eight-token exposed lineage |
|---|---|---|
| query | changed | target exact |
| key | changed | third lineage |
| value | bit-exact target | target exact |
| query + key | changed | target exact |
| query + key + value | exactly equal to query + key at all 22 faces | target exact |

The value intervention is a literal no-op because aligned layer-0 values were already exact. Its
attention return, block output, and emitted lineage all remain target-exact. Adding value to the
query+key intervention changes no captured bit.

Query-only changes the receivers associated with the imported occurrences but does not
automatically alter every later receiver. The positional cone makes the distinction exact. The
source-declared manual occupies target positions `[131,246)`; the 115 moved aligned patch vectors
(114 manual occurrences plus one adjacent boundary) occupy `[132,247)`. Query-only changes exactly
that latter interval at both attention output and block output, while positions `[247,253)` remain target-exact.
Key-only changes every receiver in `[132,253)`, including the final prompt receiver, because every
causally later query can meet those changed keys. Query+key has the same outward positional extent
as key. Value changes no position.

Key-only is consequently the only intervention here to expose a third lineage. Importing query and
key together still changes the final first-block receiver, but later composition returns to the
target presentation. The faces are therefore mutually composing and directionally asymmetric. No
portable `manual vector`, additive feature score, or output-based correctness law explains this
cut.

## 6. What “arbitrary embedding spaces” can now mean rigorously

This run establishes one local chart, not a universal latent space. A second tokenizer/model need
not share token IDs, rank, coordinates, basis, or numerical format. Its lawful overlap can instead
be constructed through:

1. the same source inscription and exact span/event incidence;
2. each tokenizer's own covering of that source into categorical occurrences;
3. each model's own typed embedding, query, key, value, branch-return, and presentation faces; and
4. matched source changes and causal substitutions, compared as incidence and transport diagrams
   rather than direct coordinate equality or cosine proximity.

Commonality would then mean that some relational diagram recurs under the chart transition—for
example, moved source material retains its initial categorical placement, chronology changes its
addressability, and that changed field reaches a later receiver. It would not mean that coordinate
17 in one model is coordinate 17 in another. No second model chart has yet been measured.
