## Question

Can complete typed paths returned by a bounded world become a receiver-relative exact ecology
which re-instantiates an unseen path after every teacher has departed?

## Source

Six complete causal DAGs cross in chronological order:

- three integer ADD paths over `1+2`, `1+3`, and `2+2`;
- three text CONCAT paths over the same inscriptions.

Each path contains two typed literal nodes, one binary operation node with exact antecedent
indices, and one return node. The source contains no answer table, float, inherited tokenizer,
embedding, transformer, attention weight, MLP, MoE router, or classical quantization law.

## Accepted result

The resting ecology contains:

- 11 exact inscription spans;
- 7 recurrent constituent folds;
- 6 receiver-relative occurrence fibers;
- 2 execution fibers;
- 2 active complete-path templates; and
- support 3 for each active template.

After exact rest/remount:

| Probe | Receiver | Complete result |
|---|---|---|
| `1+4` | symbolic + arithmetic | `Literal(1), Literal(4), Add(0,1), Return(2)` → integer `5` |
| `1+4` | symbolic + concatenate | `Literal("1"), Literal("4"), Concat(0,1), Return(2)` → text `14` |
| `1+4` | symbolic; objective withheld | both complete paths remain |
| `1+2+3` | symbolic + concatenate | bindings `1 | 2+3` → `12+3`; `1+2 | 3` → `1+23` |
| `1*4` | symbolic + arithmetic | no afforded path |

The no-standing control returns no path. Every complete path evaluates to its carried output. Every
successor is one exact outgoing factor. Every teacher path, inscription current, replaced ecology,
and source lineage departs. The final ecology remounts exactly with zero live lineages.

## Interpretation

The learned object is not the scalar answer `5` or `14`. It is the exact relation among:

1. a recurrent constituent surface;
2. a receiver face;
3. open literal slots;
4. a complete typed causal DAG; and
5. its returned consequence.

The same surface can therefore recruit different complete paths without being assigned one
absolute meaning. With insufficient receiver context, the paths remain plural.
