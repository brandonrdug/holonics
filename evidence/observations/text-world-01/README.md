# TEXT WORLD 01 — persistent source horizon and literal typebar

This observation is the first direct construction under `FORMULA §XLVIII`. It is not the elastic
lifecycle overlay and it is not a fixed one-snippet probe.

`plan.json` declares a sequence of independently selectable source horizons. At every passage the
Rust boundary presents three co-present cohorts to the same CUDA edge:

1. the readable visual horizon;
2. the contemporary writable typebar world;
3. the exact UTF-8 material visible in that horizon, plus any explicitly declared material paths.

The source field is never painted over. The typebar world persists independently as physical
segments, joints, articulations, and literal simultaneous key configurations. Every passage writes
the successor SLEEP body, complete raw radiation, compact world action, readable edge output,
cumulative output, exact source material, and both world states/fields.

Run from `src/soma`:

```text
cargo run --release -p life -- boundary text observations/text-world-01/plan.json
```

The output directory is create-new. Change `output` before another run. Source choice, vertical and
horizontal position, wrapping, horizon extent, and supplemental co-present paths are all explicit
plan inputs; the application carries no fixed source snippet.
