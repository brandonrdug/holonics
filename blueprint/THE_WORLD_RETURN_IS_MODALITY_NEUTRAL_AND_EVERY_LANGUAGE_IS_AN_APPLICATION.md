## 0. Correction

[definition] Languages, proof assistants, modalities, formats, compilers, kernels, sensors, tools,
and worlds are applications. They may supply occurrences to a neutral HNA port and may render or
inspect emissions. They do not determine Athena's topology, native state classes, local current,
constitutive morphology, recurrence, or output format.

[counterexample; source-inspected] The earlier WRN revision removed Lean names but retained the
same deeper mistake. It made an application return a `WorldFace` family, interpreted a process
status as admission for every emitted grain, calculated current and storage from admitted counts,
and used that result to stage a morphology commit. This was reafference-shaped contamination: it
gave an exterior verdict a privileged causal role which an ordinary successor operation does not
need. `WRN0--WRN6` are withdrawn and schedule nothing.

[definition] An external action may still matter. Its result becomes another ordinary occurrence:

```text
operate(E_t, o_t) = (emission_t, trace_t, E_(t+1))
application(emission_t) = o_(t+1)          -- when an application acts
operate(E_(t+1), o_(t+1)) = ...
```

The application result is not a reward, teacher, returned current, candidate morphology, or commit
permission. It is simply material for the next operation.

## 1. Neutral occurrence and emission boundary

[definition] An application may submit:

```text
Occurrence {
  port,
  carrier section,
  application lineage,
  optional apparatus testimony
}
```

The native operation validates the declared carrier and port and either advances the ecology or
returns an obstruction. The application may not submit a native state identifier, internal route,
morphology delta, expected answer, or semantic class.

[definition] One native operation returns:

```text
Successor {
  emission,
  exact operation trace,
  successor ecology,
  open obstruction population
}
```

The successor ecology is the only predecessor of the next operation. No `WorldFace`,
`ReturnedScaffoldInteraction`, `NativeCultivationCandidate`, admission Boolean, counted storage, or
terminal bridge belongs to this primitive ABI.

[definition] An emission is an already-produced receiver face of the native operation. An
application may serialize it as text, code, notation, pixels, samples, a process input, or another
surface. The renderer may not originate a distinction the native face does not contain, enumerate
authored candidates, copy a stored source passage as generation, or reinterpret an observation/state
identifier as content.

[definition] Self-reentry and application reentry meet at the same port. A next-token runtime,
agent tool loop, compiler invocation, proof-kernel check, optical sensor, and user reply differ in
application provenance, not in the engine's recurrence law.

## 2. Mouth and recovered incidence

[definition] Raw octets are an exterior carrier face, not native current. A lawful application
mouth may expose octets, coordinates, carrier handles, or an application-side tensor face at a
declared port. The native operation must still derive its current by applying contemporary
constitutive morphology to the supplied carrier through admitted incidence.

[counterexample] The following do not found native incidence or current:

- adjacent byte differences, including a first byte measured against an authored zero;
- a parser, tokenizer level, syntax tree, language atlas, or filename relation;
- an application-declared reference graph presented as recovered structure;
- equality of source bytes, hashes, state identifiers, or observation identifiers; or
- a process status, accepted count, score, loss, or expected output.

[definition] Where an application already possesses a declared structural relation, it may submit
that relation as application testimony. This does not establish that Athena recovered or learned
the relation. A recovery claim requires the relation to arise through the common native operation
and to retain its receiver/preimage boundary.

## 3. Weight, cross-section, current, and the recurrent operation

[interpretation] In a declared linear chart, a weight or coupling matrix `W` may present a
constitutive flux cross-section. For a contemporary carrier vector `x`,

```text
J_i = sum_j W_ij x_j
```

is the current in that chart. `W`, `x`, and `J` are different objects. The matrix does not become
current until it operates on the carrier, and the carrier does not become current merely by being
encoded numerically.

[definition] The architecture-neutral law is the HNA local operation:

```text
J_(E,g,x)(i,j) = LocalCurrent(E.morphology, g, x, i, j)
x'(i)          = Reaction(E.morphology, g, i, sum_j J_(E,g,x)(i,j))
E'             = Advance(E, occurrence, x')
```

The operation, not a world verdict, determines the successor ecology. An application receiver may
observe any scalar, vector, matrix, tensor, status, or artifact face afterward.

## 4. Morphology, artifact, tensor lens, and preimage

[definition] The construction vocabulary is:

| Role | Name | Meaning |
|---|---|---|
| inherited source-neutral handoff | `NativeTransportScaffold` | temporary structural material; not itself an operable model unless it supplies the complete local operation |
| continuing hot ecology | `NativeHolonMorphology` | the move-owned constitutive morphology inside the complete ecology |
| durable rest | `NativeMorphologyArtifact` | a validated serialized occurrence which remounts the morphology it actually contains |
| broad separated evidence | `MorphologyTestimonyLane` | lineage, preimages, separators, evaluation, realization, and open obligations without identifying them as one fibre |
| coordinate map | `MorphologyTensorLens` | an application-owned receiver into declared dependent tensor coordinates |
| returned coordinate value | `MorphologyTensorFace` | the scalar, vector, matrix, or higher-order face returned by that lens |

[definition] `NativeMorphologyArtifact` is a storage classification, not a learning grade. Exact
rest/remount proves that the stored carrier reproduces its contained morphology; it does not prove
that the morphology was learned, useful, source-neutral, or causally responsible for an output. A
serializable value which lacks the rest/remount law is a `NativeMorphologyCarrier`.

[definition] `NativePreimageFibre` is reserved for the complete inverse image of a declared map.
An exact copy of source bytes, a locator, an identity matrix fitted to one value, or a list of known
examples is not a preimage fibre without the map and the complete population returning the same
face. A particular affine solution plus radical earns the name only when the radical spans the
complete kernel.

[definition] Actual inverse transforms, remounts, decoding procedures, and recovery operations may
retain reconstruction terminology. Literal inverse-image populations use preimage terminology.

## 6. Retained application controls

[established-bounded; source-inspected] Process execution, compiler or kernel invocation, exact
