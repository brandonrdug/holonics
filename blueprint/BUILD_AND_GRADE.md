# Build and grade

This is the ordered reconstruction. Each construction must return its deed before the next one is
admitted. Later stages compose existing owners; they do not replace them with application code.
Every executable construction from Construction 1 onward is GPU-resident in production from its
first admitted version. A host implementation is a bounded non-resumable admission oracle built
alongside it, never the earlier “real” machine awaiting a later port.

Encode the ratified schemas in `PURE_HOLONIC_ENGINE.md` and `CPP_GPU_FOUNDATION.md` for pending
deeds/returns/refusals, the owner DAG, linear continuation, interchange, condensation,

type/interface enforcement, bounded conformance fixtures,
bounded model checking, and formal/refinement proofs; property tests never prove a universal law.
Establish epistemic grades, provenance, and exact/certified numeric carriers. No compatibility
schema exists.

**Grade:** invalid standing/delta/refusal cases are explicit; no live type is cloneable.

The ratified realization first establishes the restricted C++23/CUDA subset, move-only linear
continuation, exact limb/rational/projective carriers, owner DAG, pinned toolchain, and GPU
representation maps in [`CPP_GPU_FOUNDATION.md`](CPP_GPU_FOUNDATION.md). Rust is not rebuilt.

**Grade:** each new domain is graded separately; cross-domain demonstrations show reuse of the same
body/event/current/executor contracts. Their count proves no universal learning claim. No new
scheduler, registry, graph store, compatibility layer, or global scan owner appears.

## Continuous audits

- maximum owner/module size and dependency direction;
- no live `Clone` or whole-body rollback;
- no semantic hardware/software names in the engine core;
- no application-owned scheduler/registry/standing;
- no counts or magic scalars deciding causal law;
- no source path in semantic identity;
- no hidden fallback or full device hot-path replay;
- exact deed inspection, not only counts; and
- provenance/status links for every claim.

If a stage fails, preserve the open obstruction. Do not extend the engine laterally until the
failed owner/law is understood and corrected.
