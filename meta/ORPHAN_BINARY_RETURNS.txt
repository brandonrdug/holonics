THE FIFTEEN ORPHAN BINARIES AND WHAT THEY RETURNED
==================================================

Fifteen example binaries stood in `target/` whose sources are committed at NO commit in this
repository -- `git log --all -- "*<name>*"` returns 0 for every one -- and whose sources are no
longer in the working tree either. One `cargo clean` ends all fifteen. That is `CLAUDE.md` section 0
lesson 1's loss pattern exactly: the shape that took the laboratory's tiger figures and
`semantics_invariant_under_exact_chart`, both of which survive only as names.

The binaries could not be un-lost -- a binary is not a source and this file does not pretend
otherwise. What could be saved is WHAT THEY RETURN, so each was run on 2026-08-09 and its return is
recorded here verbatim. The origin path is read out of each binary's cargo dep-info (`<bin>.d`),
which still names the source file that no longer exists.

`research/records/2026-08-09_THE_COMMITTED_BOUNDARY_ARTIFACT_IS_STALE_AND_CANNOT_BE_REBUILT.md`
section 4 named TEN of these. The true count is FIFTEEN; the five it missed are
`_probe_lean_ecology`, `ron_probe`, `scratch_probe_decomposing`, `zzy_kernel_teeth_probe` and
`zzz_adversarial_probe`, and the last of those is the most load-bearing return in the set.

These are UNGRADED returns from binaries whose source cannot be read. Nothing here may be cited as
established: a receipt whose implementation cannot be inspected is exactly what `CLAUDE.md`
section 8 forbids grading on. They are recorded so a later session can rebuild the organ and compare,
not so anyone can quote a figure.
