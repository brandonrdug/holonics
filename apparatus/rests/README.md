# Frozen predecessor rests

A rest image whose producing deed has been annihilated, retained as the constant
it already was.

`INHERITED_PREDECESSOR.rest` (320 octets) is the handoff the R17 geometry-inquiry
deed emitted. That deed was cut on 2026-08-06: every verdict-bearing field in
`organ/geometry_inquiry_law.hpp` was a compile-time constant for every admissible
input, and `probe_geometry_inquiry<<<1,32>>>` burned the card recomputing a folded
constant.

The rest it produced was therefore **already a constant**, and the phases that
chain off it lose nothing by mounting it directly. This is not a fixture standing
in for a computation; it is the computation's only possible output, retained.
