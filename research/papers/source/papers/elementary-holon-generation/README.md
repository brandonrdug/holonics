# Elementary Holonics: objects, generation and coupled fields

This ten-page synopsis renders the maintained design in `docs/HOLON.md` and
`docs/HNN_FORMULA.md`. It presents the formal object, joint field generation, nested
communication, reconstruction, modal encoding and the native operator assembly.

The geometric plates reuse the existing Information Chemistry torus, receiver engraving,
contact, knot-wave, woven-field and lobe sources with the original page/style conventions.
Holonic entity marks and the existing Dirac helpers present tensor-valued computational
objects, contractions and interaction vertices. Recursive IFS and analytic-operator plates
include the subsequent fractal/transcendental paper synthesis.

The reusable equations and diagram functions live in
`research/papers/source/holonics/computational-holon.typ`; `main.typ` is their presentation
consumer. Formal statements live in Lean, and the existing Rust owners retain implementation.
The figures retain their geometric/constitutive source laws; they are not outputs of a
newly trained model. The source diagrams and original paper editions remain unchanged.

Build from the repository root:

```bash
typst compile --root . research/papers/source/papers/elementary-holon-generation/main.typ research/papers/rendered/elementary-holon-generation.pdf
```

The September 14 generation/Holon record retains source recovery, primary-paper comparisons,
formal checks and visual verification. This synopsis does not replace the broader mathematical
synopsis or establish a second construction order.
