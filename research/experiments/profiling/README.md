# Historical Nsight profiling instruments

[historical; source-inspected] These scripts were last substantively developed on 2026-08-19
for scalar and streamed-circulation experiments. They read external Nsight/proc measurements;
they do not decide semantic correctness or gate code changes.

They remain available because measurement methods can be reused. Check the export schema,
apparatus constants and intended receiver before applying them to a current HNA run. They are
not automatically invoked, and their old observations do not describe current performance.
