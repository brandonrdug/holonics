# Oriented split transport through the existing matrix owner

[definition] This is the conditional source relation `x*y=T` and its oriented passage
`x'=(x+hT)/(1+hx)`. Its homogeneous matrix is `[[1,hT],[h,1]]`. For positive T,x and
`0<=h`, `h^2*T<1`, the passage preserves the side of `x^2-T`, is reversible and lowers
`W=x+T/x`. These laws are proved in `Millennium/Navigation.lean`.

[definition] The public mathematical session constructs the matrix and its 1st, 4th and
16th powers, then applies those resident operators to two origin sections. The requests
retain both homogeneous coordinates. Division is an exterior affine readout; the inverse
matrix recovers the source. Every observed signed residual and work difference stays in
the result. No square root is evaluated to generate the trajectory, and no candidate set
is ranked. The exact observer independently multiplies the matrix to verify the returns.
