[definition] The first witness uses source-only rational elimination. It then independently
multiplies its integer coefficients against every original source and arriving coordinate:

rational multiple of the actual first vertical native relation row. It separately evaluates the
full per-node Hermitian pair receiver, retaining real and imaginary terms.

[definition] The second witness searches actual linked source/receiving pairs for identical
complete local source fields and different arriving fields. It retains both arrivals, their

whether both collision sources were among the saved device observations.

receiver, not an impossibility result for native contextual transport or language.
