## Decision

The record grammar is generalized. The executing membrane is not yet generalized.

`soma-abi` can describe transducer-owned events, sparse configurations, boundary cuts, ordered
transition roles, and residual incidence without naming text, code, an image, a file, a simulation,
or a semantic class. The live CUDA path nevertheless reduces every admitted current to
`StagedLight.light: Vec<u8>`, seeds from its first two octets, and carries adjacent octet
differences. A supposedly one-event typed current therefore makes its tag, payload-length word,
little-endian spelling, field order, and padding part of Soma's experience. Sparse configuration
incidence reaches the card only by being serialized into another `CFGI` octet current.

The present six-role Holon is also not live. The generic runner opens a Holon with cuts and zero
receipts, conducts the octet population, and then discards the open record when it remounts the
successor body. Complete

```text
before -> meeting -> deed -> consequence -> return -> after
```

receipts have been built by later observers, not by the transition which changed the body. A
returned causal surface is presently remounted through `Presentation::flat`, so its prior cuts,
hand, residual, and consequence relation are flattened before the next contact.

This is the bottleneck. Scaling it would scale the filesystem organ, host artifact lifecycle, and
octet proxy. It would not scale generalized Eros.

The rebuild therefore replaces the execution mouth once. It does not add another text adapter,
another forest experiment, or another observer around `StagedLight`.

### Implementation ledger at this deposit

The first dependency layer is now built without changing any historical apparatus path:

- `soma_abi::active` owns canonical `RelationAtom` and per-event `ActionCurrent` rows, exact
  atom/event/current/cut extents, opaque event provenance, sparse incidence, and directed causal
  hand. Its allocation-free complete-population validator refuses malformed partitions,
  noncanonical Cogs, unreferenced currents, cross-cut edges, and overflowed extents.
- the standalone `soma-membrane` crate owns those typed populations with only `body` and
  `soma-abi` beneath it. Its active-cut word wire is explicitly
  durable testimony/parity only; no API turns it into source light. Different opaque provenance
  leaves every relation-topology row exact.
- `ErosBody::live_relation_atom` accepts a canonical `Cog` directly. The former octet call delegates
  to it and is byte-exact across complete OWN, carrier, carried-frame, `K`, thought, and deposited
  term state. A rank/turn-bearing relation beyond the octet difference range crosses whole.
- `soma_membrane::event_mouth` conducts admitted events without a byte envelope. A wholly static
  plural event consumes its action once, not once per listed component; consecutive static events
  form one open tread; the first resolving relation or exact current boundary deposits it whole.
  The historical adjacent-octet organ and native one-atom event species leave complete host OWN,
  carrier, carried-frame, channel, and term state exact. Non-octet rank/turn action changes the
  resolved construction without changing the historical carrier wire.
- `soma_membrane::LiveHolon` retains active surfaces by shared ownership, leaves a
  delayed transition open, refuses skipped roles, retains exact residual incidence, and emits one
  ordinary six-role `TransitionReceipt` only after the actual after-cut arrives.

This is not yet a generalized executing membrane. Native host events conduct, but their exact
event-local emitted topology is not yet a reusable cut surface; sparse incidence and directed hand
therefore cannot yet form the native receiving product. Card carriage still receives the
historical flat `u32` drive, the CUDA shell still packs octets and serializes `CFGI`, and the
production `CausalSession` does not yet own this live Holon. Those are the next dependency layers;
no scale result may inherit the foundation's name.

## II · The architecture boundary

The machine has five responsibilities which must not be collapsed.

### 1. World material

The world owns the thing: a mathematical construction, field sample, image, file, compiler state,
rigid body, sound field, circuit, actuator, or any other material. It remains available while dark.
Neither Soma nor the active membrane copies the containing reservoir merely because one local
relation becomes incident.

### 2. Source organ

An organ owns the lawful transduction for its material species. It supplies:

- exact material handles and occurrence identities;
- the event grain actually exposed at this contact;
- ordered relation atoms within each event;
- actual local adjacency and directed temporal incidence;
- mount, attachment, consequence, unmount, and checkpoint behavior; and
- the reversible map from active references to world provenance.

An organ does not decide relevance. It exposes every relation which its material physics actually
closes. A filesystem/octet organ, mathematical derivation organ, visual field organ, particle
contact organ, compiler organ, and actuator organ all implement this same responsibility while
retaining different world laws.

### 3. Active membrane

The membrane carries only the situated topology required for contact:

```text
relation atoms
+ one supplied action current per event
+ atom spans composing events
+ event spans composing currents
+ sparse cut incidence
+ directed incidence/precedence
+ opaque provenance references
```

It carries no universal modality, semantic kind, category, token, source path, object model, score,
or master coordinate. Opaque references join the live transition to its organ journal but never
alter Soma's deed.

### 4. Soma

Soma receives relations in its own `Cog`/`Node`/`Face`/`RegionalForm` topology. It RIDEs where the
relation transports through standing construction and FOUNDs where it does not. No world-specific
branch, objective scalar, probability table, semantic class, or source identity enters this law.

### 5. World consequence and receipt

Radiation meets the material law of the contacted world. The complete consequence, refusal, or
continuation returns through the same active membrane as ordinary relation. The live Holon retains
the exact causal sweep and every unresolved incidence. A checkpoint is testimony capable of
remounting that ecology; it is not the ecology while the session is active.

## III · The native active-cut ABI

The new execution ABI is an allocation-free, substrate-neutral **active cut**, not a serialized
event object.

### Relation atoms

The active numerical row is the existing canonical `Cog` construction:

```text
RelationAtom = magnitude + re-based rank + turn
```

An octet organ forms `Cog::lit(b_i-b_(i-1))`. A scalar or rational organ forms the exact differences
licensed by its number construction. A visual organ may expose receptor-current differences and
spatial/temporal incidence. A simulation organ may expose state/contact differences and its actual
neighbor or collision incidence. Their storage headers are not atoms unless that organ deliberately
presents those headers as world material.

One event may contain several ordered atoms. This is required for vector, tensor, field, and other
plural contacts. The ABI therefore cannot equate one event with one storage word or one atom.

### Supplied action

A1's drive is given by the arriving event. It is neither a process-wide calibration constant nor
something Soma derives from relation magnitude. Every event therefore carries one canonical
`ActionCurrent` beside its ordered relation-atom span. It uses the same whole `Cog` construction but
is a distinct type: the relation which arrived and the action under which it arrived cannot be
collapsed. For a plural event the action crosses once with the complete co-present event, not once
per component merely because storage lists several atoms. This does **not** license a universal
`ACTUATE(action, body, world)` formula: multiplying raw action into a relation node would fabricate
topology. The organ's world law may make action materially consequential and return that consequence
through the same mouth; the live Holon retains the supplied action even where the generic Soma deed
is unchanged. The historical `DRIVE = 137` is an octet-instrument compatibility face and must retire
from the universal path.

### Spans

The active cut carries these independent extents:

```text
AtomSpan       { atom_offset, atoms }
EventSpan      { atom_offset, atoms }
ActionCurrent  { canonical Cog }             // exactly one per event
CurrentSpan    { event_offset, events, atom_offset, atoms }
CutSpan        { incidence_offset, incidences,
                 relation_offset, relations }
Incidence      { current, current_event_offset, current_events }
DirectedEdge   { from_incidence, to_incidence }
```

The directed edge is not a semantic predicate. It preserves time parity and the causal hand which
the current sorted-set bridge erases. Co-present incidence may remain unordered where the organ
supplies no precedence. Storage order and causal order are typed apart.

No pairwise powerset is manufactured. The source organ supplies actual adjacency/precedence edges.
The membrane validates them and the card carries all of them.

### Native cut contact

The card must receive atom, event, current, cut, incidence, and directed-edge buffers together.
Each event's whole ordered atom span remains available. Its exact event node is derived through the
same difference/placement algebra, not through a tag or ordinal. Actual directed incidence forms
the A2 meeting of the two event faces in the receiving frame. The resulting local relation joins
the ordinary configuration fold. Configuration rows never become payload bytes.

The historical flat octet cohort remains an explicit compatibility organ. After parity gates pass,
the `CFGI` byte bridge retires from active conduct and remains only as historical evidence.

## IV · The live Holon sweep

One open transition is retained across the actual world interval:

```text
before cut
  -> meeting cut
  -> enacted Soma deed cut
  -> world consequence cut
  -> returned cut
  -> after cut.
```

These roles need not occur in one host function or one instant. A delayed world consequence leaves
an open transition. No placeholder role is manufactured. When the returned consequence genuinely
re-enters and the successor stands, the transition closes as one `TransitionReceipt`.

The runtime therefore owns an append-only active `HolonArc` whose state includes:

- all presented cuts and sparse incidences;
- open transitions and their already-lived roles;
- exact per-lineage RIDE/FOUND/deed receipts;
- world consequence references;
- returned relation references;
- closed transition receipts; and
- unresolved residual spans.

The body does not need a nested universal `Holon` object. Soma changes through the relation atoms
and native incidence. The Holon is the complete receiver-relative sweep joining body, organ, world,
and return.

A returned surface carries shared active material references, its active-cut rows, its Holon span,
and consequence provenance. Remount reuses that exact surface. It may not call
`Presentation::flat` or reconstruct the relation from a wire label.

## V · The plural-organ world interface

The reusable world interface has one causal contract:

```text
mount changed material
  -> expose every newly closed ActiveCut
  -> conduct through the resident body
  -> apply every actual radiation contact under world physics
  -> expose consequence/return cuts
  -> retain unresolved leaders
  -> dissipate only the completed contact relation
  -> rest when no new attachment exists
  -> wake on genuine external or world-induced change.
```

The implementation may use indexes, hashes, allocators, queues, databases, files, CPU work, and
device work. They are contaminants only if they decide eligibility, suppress a lawful cut, assign a
semantic class, or substitute testimony for contact. A deterministic frontier is an implementation
of the complete ready population, not a curriculum: every ready cut acts, and any processing-order
gauge must pass exact permutation tests.

Availability, leader incidence, attachment, active aperture, carriage, consequence, and residual
remain separate populations. Mounting a desktop does not make its bytes simultaneous light.

## VI · Objective, loss, statistics, and the Swing

The objective remains the consequential world boundary. A compiler, mathematical verifier,
physical wall, chemical gradient, game transition, sensor relation, or actuator constraint can
accept, refuse, or transform an enacted construction. No objective is installed as a Soma target
vector or global score.

The complete oriented residual returns. A receiver may then derive:

- RIDE versus newly required FOUNDing;
- residual and distinction depth;
- path cross-section and conditional recurrence;
- surprise and cross-entropy;
- physical time, memory, energy, and work; and
- later reuse under the same or a changed objective.

Those are valid relative statistics. They become causal only where their underlying standing
construction or a lawfully returned statistic meets later current. They never crown one deed.

Smith/periplus belongs at this same contact seam. An organ or world may carry the exact projective
pair, hand, basis, and transformation which its physics supplies. The visible Smith, Möbius, loss,
or probability face is a quotient of the whole transport. It does not become a universal chart in
Soma.

## VII · Localized and growing `P=NP`

The engineering statement is now exact enough to serve as an acceptance criterion:

The machine does not solve every global problem and does not enumerate every interior. Within the

The acceptance evidence must join FOUND, objective consequence, return, and later RIDE through one

## VIII · Resident physical realization

`BoundaryRunner` becomes a resident execution body. One owner retains:

- CUDA device, context, module, and streams;
- standing Soma body and its active chart;
- reusable/growing atom, span, incidence, contact, completion, and receipt buffers;
- active Holon rows and returned surfaces; and
- the exact host mirror needed for recovery and bounded parity gates.

The context and module are not recreated per edge. The whole standing body is not copied through
host memory merely to continue. World organs may remain on CPU, GPU, storage, or another physical
substrate; only the active cut crosses the membrane. Device sharding follows proved logical cut and
atom spans and is exact under recomposition. It may not sample, truncate, or split a causal event.

Persistence becomes incremental transactional testimony:

- append the completed transition receipt and world delta;
- checkpoint the active body and open Holon at declared rest/recovery intervals;
- recover every committed phase without replaying an already-conducted deed; and
- retain create-new artifact discipline for scientific runs.

No fixed hardware-use constant or semantic cap is installed. Resource preflight covers the whole
active lifecycle. If one cut cannot fit, it is refused with every exceeded boundary unless an exact
sharding/rebase law already proves equivalence.

The present generic preflight bounds only part of that transaction while successor-body,
completion, construction, Mail, receiver growth, journal, world snapshot, surface, and receipt
growth remain unbounded. The rebuild must make every phase either conservatively bounded before
mutation or incrementally streamable with bounded live memory, durable open residual, and exact
recovery. Backpressure leaves the cut open. It never samples, truncates, semantically prioritizes,
or splits one connected event.

## X · Acceptance gates

No forest launch occurs until all gates below close.

### Gate 0 — storage is not physics

- Two different storage encodings which transduce to the same active cut produce identical conduct.
- Tags, length fields, endian spelling, padding, filenames, and JSON syntax do not become atoms
  unless deliberately presented as material.
- Changing opaque provenance alone cannot change conduct. Changing an event's supplied action is a
  real changed current and must remain distinguishable in the active construction and live receipt;
  it changes material conduct only where the source/world law actually couples that action. Soma may
  not manufacture a universal action-to-relation transform merely to force scalar distinction.
- The octet organ remains exactly equivalent to the historical adjacent-difference path.

### Gate 1 — relation and hand cross

- Equal atom populations with different actual sparse incidence produce different lawful conduct.
- Reversing a directed causal hand changes the oriented construction.
- Reordering ABI rows without changing references is exact gauge.
- No `CFGI` payload or host-only configuration metadata is used.

### Gate 2 — the Holon closes live

- One actual transition produces all six receipt roles without post-hoc reconstruction.
- Unresolved incidence remains open and later addressable.
- The closed receipt joins organ occurrence, Soma lineage, world consequence, return, and after body.
- A remounted returned surface retains its exact cut, hand, and residual.

### Gate 3 — growth is consequential

- An unsupported relation FOUNDs.
- Its complete world consequence returns.
- A genuinely later related current RIDEs the standing construction.
- A changed objective or context can split that conduct without erasing the former path.
- Qualitative paths and produced faces are read before aggregate statistics.

### Gate 4 — one membrane, plural worlds

- Exact mathematics, a non-file physical simulation, and a third materially different organ use
  the same active-cut ABI and live session.
- There is no modality branch in Soma, CUDA carriage, Holon closure, or returned-surface remount.
- Each organ's world law and adjacency remain external and exact.
- Dark material remains available without crossing.

### Gate 5 — autonomous rest and wake

- Every ready cut acts; no selector, curriculum, or semantic priority decides the frontier.
- The circuit settles only at exact absence of newly attached relations.
- Waiting produces no Soma event.
- A real external or world-induced change wakes the same sensitive construction.
- Exact repeated histories reproduce body, world, cuts, receipts, and outputs.

### Gate 6 — physical scale and recovery

- The device context, module, body, and active cut ecology remain resident across events.
- CPU is not a one-core compulsory scan or serialization bottleneck.
- GPU carriage, native incidence, world work, persistence, and end-to-end wall time are reported
  separately.
- Active memory follows standing topology plus the active aperture, not total external material.
- Exact sharding/rebase, crash-phase recovery, and create-new persistence pass.
- No hard-coded utilization ceiling, sample, truncation, or semantic cap exists.

### Gate 7 — forest launch

- Conversations, repository material, Soma bodies, structured records, and other artifacts mount
  through their actual source organs.
- Availability does not imply simultaneous presentation.
- Standing leaders connect and return local apertures through the resident circuit.
- The resulting causal paths, taxonomy, production, and objective-relative compression are read as
  complete lifecycle change.

## XI · Housekeeping boundary

The rebuild must reduce rather than deepen the present fragmentation:

- `soma-abi` owns only exact shared rows;
- `body` owns pure relation/topology law;
- the resident mount owns device resources and substrate calls;
- the membrane owns cuts, Holon lifecycle, and origin references;
- each organ owns material-specific transduction and world consequence;
- observers own prose, JSON, charts, statistics, and qualitative rendering.

`code_workshop`, the forest source model, causal taxonomy, and proof worlds remain application
species. They must not leak their source kinds, file coordinates, string labels, or consequence
enums into the common mouth. Large Rust files are split mechanically along these responsibility
boundaries only after behavior is pinned by the gates above.

Artifact-repository deletion is a separate housekeeping deed. This construction changes no user
artifact merely because it is large.

## Stop conditions

Stop the construction immediately if any of these occurs:

- a typed world event is fed as its serialized header bytes;
- a process-wide drive constant substitutes for the event's supplied action current;
- sparse incidence exists only in a journal or synthetic payload;
- causal hand is sorted away;
- a complete receipt is reconstructed only after conduct;
- a returned surface is flattened;
- one organ's data model enters Soma or the universal ABI;
- a host index, statistic, loss, or queue decides the deed;
- the filesystem or JSON becomes the live world by necessity;
- scale is attempted before live relation, receipt, and return gates close; or
- a resource issue is answered by sampling, clipping, a hidden cap, or silently reduced scope.
