The probes of §17 (host, debug build, November 1). Each line is one probe: its task (0 the
permutation and cue, 1 the word before, 2 the key-value recall; the rate-4 and rates-6-9 files are
task 0), its opening (plain=true the site's own class alone, plain=false the strand contacts) and
rate, then at each checkpoint `sections:held` or `sections:held/train/deposited/halvings`, the held
code and the sections' own code before their steps in millibits a site, the steps deposited so far
and the halvings since the last checkpoint. Width 16, two heads of four modes (two still unless the
file name says four), 16 contacts, two ticks, two ring sets, 16 regions a section, 64 held regions.
