## Native receiver and application boundary

[definition] `normal/direct/wave/basis.rs` and `normal_wave_basis_face.cuh` implement the declared
unit complex basis receiver. For coordinate permutation π, `s_a=Re(c_π(a))` and interval
`[s_a−r,s_a+r]` project one Euclidean enclosure. The device selects maximum centre score, first
receiver address on exact equality; the report carries the exact tie count. Strict interval
separation is an optional robust-winner certificate. Overlap does not stop this declared projected
action, identify the source, or admit independent choices from the coordinate intervals.

[definition] Native score storage is signed-wide centres plus one shared radius. Wider
`HistoryInteger` gap arithmetic compares against twice that radius; interval endpoints can exceed
one signed-wide value. The cold exact-rational decoder computes their endpoints without affecting
selection. The original current, fibre and chart remain retained by `NormalWaveBasisFace`. The
first chart supports coordinate permutations, not arbitrary unimplemented unitary transformations.
No device semantic float, point-current cast or host score ranking enters this passage.

[definition] `SymbolCurrentChart` maps the native address to alphabet octets and transports its
coordinate permutation through source mounting and rest. `NativeWaveSession` owns the moved
Applied wave and exposes actual input, emission and addressed observed-symbol return through the
shared `HnaStream`. `next_symbol` advances once; `predict_symbol` additionally retains an explicit
producing handle. Selecting a symbol adds no learning observation. After the first actual emission,
each consecutive emitted pair in the same output part enters ordinary source actuation. New actual
input starts a fresh exterior output-part adjacency. No padding, synthetic end marker or selected
centre is supplied as native observed truth.

## Refusal, rest and transport

[definition] The session records Ready, AwaitSelection and AwaitReentry phases. After a generation
succeeds, selection or re-entry refusal retains a retryable phase; retry does not generate again.
Requested full readouts occur before the final native re-entry mutation. Complete rest retains
native material/current/pending comparisons, alphabet/permutation, last actual emission, pending
phase and shared delivery cursor. Rest validates those chronology/chart relations before mounting.
A model attachment refusal returns its wave owner recoverably.

[definition] The existing stream drains a pending event before admitting another request. A fresh
connection may replay the same event identifier; this is not an exactly-once peer-delivery claim.
The workbench `hna wave-session` command accepts the previous Applied model directory or resumes
this session artifact. The [native interface guide](../../docs/NATIVE_HNA.md) describes the commands.
Source models and raw checkpoint/event files remain private under `.local`.
