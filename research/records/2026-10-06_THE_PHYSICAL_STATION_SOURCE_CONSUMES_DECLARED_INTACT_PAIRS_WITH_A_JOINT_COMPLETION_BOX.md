## Joint completion enclosure

[source-derived interval law; native pending] The sparse point and the full completion family
are distinct operands, as in the accepted first-marginal domain. For N stations and delta<N,
every full completion has pair population N-delta. Its leaky denominator in integer lattice
units is

```
Z_delta = sum_(j=delta..N-1) nearest(U*rho^(N-1-j)).
```

It is independent of completed classes. For each phase and ordered slot (x,y), forced matching
known-known edges contribute to the lower count. Every edge whose endpoint restrictions admit
(x,y) contributes to the upper count. Unknown shared endpoints can correlate different edges;
dropping that correlation enlarges this coordinate box. Applying the actual monotone population
chart to each endpoint over the same Z_delta encloses every rounded table entry. No monochrome
support replaces heterotypic slots. Delta>=N returns zero tables before any denominator
subtraction. An unsupported nonpositive transported denominator returns an uncertified domain.

It adds that box to the existing first-marginal box for unit and leaky sources. The radius is
read from the actual sparse opening to those full-family endpoints, so it also contains the
sparse point. The unchanged exact coupled tube consumes this opening box through its loaded
