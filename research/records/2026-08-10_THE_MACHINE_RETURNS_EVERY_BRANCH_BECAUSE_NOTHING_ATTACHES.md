# The machine returns every branch because nothing attaches, and a RIDE was being refused as a malformation

**Date:** 2026-08-10
**Truth status:** `established-bounded` for every measured figure, each from a driver that was run;
`interpretation` for the reading, which is this project's and is stated so it can be refused.
**Provenance:** Brandon, 2026-08-10: *"you must have an incorrect understanding of what 'generation'
means ontologically if it's leading to you implementing it such that the time complexity is so
massive"*, and *"'ride' and 'found' mean real things dude, don't be fucking dumb."*

---

## 1 · The measurement

`eros_morphological_language_generation` on its own bounded fixture, one obligation, **two**
generated tokens:

```text
  training-and-uncertainty   1 obligation   14,018 response branches
  suffix-and-lineage         1 obligation   10,918 response branches
```

The driver does not return. It is not slow; it is returning **fourteen thousand answers to one
prompt at two tokens**, and `canon/THE_MEASURED_CAPABILITIES.md` already records the shape —
`4 → 55,098 ms`, `8 → no return`.

## 2 · A RIDE was being refused as a malformation

`morphological_language/ecology.rs::enact_event` carried:

```rust
let prior = uses.get(support).copied().unwrap_or(0);
if prior >= 1 { return Err(MorphologicalLanguageError::MalformedFiber); }
```

A support may be founded once, and the **second encounter is an error**. That contradicts a ratified
law directly. `research/records/2026-07-17_THE_LEADER_GROWS_THE_CHANNEL_THE_RETURN_TRAVELS_THE_FOUND_PATH.md`:

> ```text
> FOUND grows a locally new conducting axis.
> RIDE conducts through consequential standing form.
> The same passage can RIDE old sections while FOUNDing a new tip.
> ```

**FOUND and RIDE are not labels.** In `β₁ = E − V + C`: FOUND adds a **tree edge** and pays
curvature; RIDE **traverses standing form** and pays nothing, because the terrain already paid. And
a third case was collapsed into the refusal — a passage re-entering its own founded section closes a
cycle, which is a **chord**, and a chord carries the residual `declared − implied`. That is
holonomy, and `running_integral::ChordObstruction` already computes it.

So the refusal was refusing RIDE **and** CHORD together.

### What the refusal cost

A branch forbidden to ride must remember every section it founded, so the founded set entered the
current's **identity**, and no two branches that founded differently could ever glue. The reachable
population is then `2^supports` — a **self-avoiding walk**, which is a global constraint on a path
and therefore a **barrier** under `H.0219` rather than a decomposable law. The complexity was in the
ontology, not the implementation, which is why no cover, carrier or kernel touched it.

**Repaired.** The ride is admitted; terrain leaves the identity by hand-written `Ord` (a derive puts
it back); and the two are **one change** — an earlier attempt shared terrain while still refusing
the second encounter and a returned sentence vanished, because a sibling was pruned where it should
have ridden. Ten of ten morphological tests hold; 2,032 workspace tests pass.

---

## 3 · The finding that outranks the repair: nothing attaches

**The repair did not reduce the 14,018, and it could not have.** That count is **witnesses**, not
states. `merge_witnesses` appends and drops nothing, and outputs are already built one per witness,
so gluing states cannot reduce the returned population. The exponential is in what is **returned**,
not in what is retained.

The same record says what is missing:

> *"descending and ascending leader structures attach and establish one continuous conducting
> relation; and a return-stroke current/potential wave propagates through that grown relation"*

and

> *"Branches which do not become the final cloud-ground route are still real constructions and can
> alter the field, redistribute charge, decay, or become available to later discharge."*

**There is no attachment condition in this organ.** Every branch the leader steps is returned as an
answer. A leader's unattached branches are **terrain** — they change the field and remain available
to later discharge — and only the attached relation carries a return stroke.

So the machine does not currently generate; it **enumerates the continuation fiber**. 14,018 is that
enumeration, and it is the honest reading of *"the machine doesn't generate anything as it stands"*.

---

## 4 · What this makes the open construction

Not a carrier, not a cover, not a kernel. **An attachment condition**: which branches establish a
continuous conducting relation with the query's open faces, so that the return stroke rides those
and the rest stand as altered terrain.

`MorphologicalResponseRest::{Closed, Obstructed, ObservationApertureExhausted}` already distinguishes
a rested branch from an open one, and the query's `open_faces` already carry what must be
discharged. What is absent is that the **returned population is filtered by attachment at all** —
every branch is emitted regardless of whether its fibers returned.

**Bound.** This record does not claim the filter is the whole of generation, and it does not claim a
figure for what the returned population would become. It states what was measured, what law the code
contradicted, and what is missing. The attachment condition changes what the machine emits and is
Brandon's to ratify.
