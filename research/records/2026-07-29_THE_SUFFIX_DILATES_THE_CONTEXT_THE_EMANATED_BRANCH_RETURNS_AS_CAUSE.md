## Exact question

Can a partial ordered text occurrence enter the already-conditioned ecology, let
overlapping receiver scales expose a plural exact continuation family, and let
every emanated continuation return as a later cause—without looking up retained
corpus rows, enumerating an n-gram powerset, assigning probability, scoring a
target, or confusing supplied and self-emanated lineage?

The qualitative distinction is:

```text
reconstruction only:
    a received complete prefix re-exposes its received successor

generation:
    a recurrent inner path transports a successor into a different outer path,
    the resulting complete path was never received,
    and that new path can itself launch a later continuation front
```

## The singular-language correction

The phrases “one holon” and “one receiver” were being used as if serialization
had established ontology. It had not. A durable byte address may carry many
overlapping receiver fibers, and a question may simultaneously inhabit several
context scales. Neither the address, the terminal token, nor an automaton state
is the complete receiving ecology.

The generative face is therefore not:

```text
context -> selected answer
```

It is:

```text
ordered caused path
    -> overlapping recurrent suffix receivers
    -> local outgoing transports at every reached scale
    -> visible continuation branches with complete supporting paths
    -> independently returned possible-world successors
```

Equal visible continuations reached through several scales remain a single
visible branch whose distinct supports are retained. They are not duplicated
as several answers, reduced to a vote, or averaged into a score.

## Two constructions were rejected

### Token identity as a universal co-present junction

Putting every equal token occurrence into the same co-present resonance
component made common words act as universal junctions. On the complete corpus
that false topology expanded toward approximately 25 GiB of resident memory
before the run was stopped. No resource cap was installed to preserve it. The
model was canceled: equality of a token face is not sufficient evidence that
every containing utterance is in immediate contact.

### Complete prefixes as the only receiver identities

The safe replacement retained the complete prefix at every token position. It
conditioned quickly and returned 69 exact continuation branches, but every one
of those 69 complete generated prefixes had already been received. It was an
exact reconstruction control, not generation. Its receipt remains at:

```text
runs/resonant-generation-full-corpus/
```

The defect was geometric. A complete prefix admitted no lawful dilation to an
internal recurrent path, so changed outer history could not inherit a locally
supported continuation.

## The factorized suffix ecology

`ExactSuffixEcology` is a generalized exact suffix automaton over arbitrary
`ResonanceGerm` paths. The corpus occurrence paths are sorted canonically so
outer delivery order is gauge. Chronology inside every path remains physical.
Distinct boundary symbols separate utterances, so a material-only path cannot
cross from the end of one utterance into the start of another.

For `N` received germs plus utterance boundaries, construction founds no more
than `2N+1` states. Each state is a compact address of an end-position
equivalence class; it is not declared to be a complete holon. A suffix link
transports the receiver question from a longer context into its next exact
recurrent restriction. An outgoing material transition is a local star edge
from that receiver scale. Query work follows the supplied path, its suffix-link
frontier, and those local stars. It does not scan corpus rows or a vocabulary.

The root never emits a vocabulary distribution. If no nonempty suffix of a
question has occurred, the continuation family is empty.

Repeated equal utterances are not deduplicated. Each material state carries
the exact number of received ending occurrences propagated through its suffix
relations. A branch support therefore retains:

```text
(source suffix state,
 matched context length,
 target suffix state,
 exact recurrence multiplicity)
```

Multiplicity is causal testimony—capacitance enabled by repeated recurrence.
It is not normalized, converted to probability, or used to rank or select the
branch.

## Generation and return

For every question, production exposes every material transition along the
complete non-root suffix frontier. The grader supplies the actual and sibling
tokens only after this family exists.

Each emitted branch is appended to the question path, re-expressed as its full
prefix-context fibers, and received from the same trained resonance rest as:

```text
ResonanceOccurrenceOrigin::SelfEmanated
```

The source occurrences remain:

```text
ResonanceOccurrenceOrigin::Inherited
```

When a generated path touches conditioned material, the returned constituent
contains both origins without equating them. The complete returned constituent,
OPEN/RIDE topology, continuation family, and native hash remain inspectable.
The generated path is then itself presented to the suffix ecology, so its next
plural continuation family is caused by the newly composed path. No branch is
chosen as the answer. The 427 branches are 427 separately enacted
possible-world successors.

## Concrete generated topology

For:

```text
what + 's
```

the continuation `that` is supported both by the complete two-token receiver
`what's` and by the shorter recurrent receiver `'s`. Their exact recurrence
multiplicities are respectively 6 and 14. The continuation `a` is supported
only through `'s`, with recurrence multiplicity 41. Consequently:

```text
what's that
```

is received reconstruction, while:

```text
what's a
```

is a newly composed outer path. The latter immediately exposes its own plural
family, including `book`, `little`, `face`, `hat`, `bird`, and `kitty`. No
member is declared preferable.

For:

```text
that's your
```

`balloon` is simultaneously supported at context lengths 1, 2, and 3:

```text
your

that's your
```

Those three transports remain inspectable and lead to the same visible
continuation. Its returned self-emanated path then exposes `.`, `!`, `?`, and
`fell` as later branches.

## What the negative controls establish

The absent actual continuations are exact information, not scalar error:

- `your button` was withheld; the conditioned token path exposes `idea` and
  `favorite`, but not `button`;
- the `violet` token never occurs in the training paths, so `hey violet`
  cannot be induced from token recurrence;
- the `nose` token likewise never occurs in training, while
  `that's your balloon` has complete multiscale support; and
- each unseen adjacent-pair actual remains absent while its received sibling
  remains exposed.

Thus suffix transport solves the specific global-transport failure which
complete-prefix receivers created: recurrent internal paths can now carry
continuations into changed outer histories. It does not silently solve a
different relation. A token absent from the received token ecology, or a
withheld adjacency with no nonidentical connecting morphology, requires
inherited candidate material and a caused relation through which that material
can meet the current ecology. The current token-level experiment contains
neither a character/subtoken morphological transport for that candidate nor a
returned world consequence relating the nonidentical contexts. Production
therefore leaves the branch absent instead of inventing it.

This is an exact plural text generator and recurrent predictor over the
conditioned germ relation. It is not a probability model, a ranked response
policy, a semantic language closure, or evidence that equal token faces are
universal receivers.
