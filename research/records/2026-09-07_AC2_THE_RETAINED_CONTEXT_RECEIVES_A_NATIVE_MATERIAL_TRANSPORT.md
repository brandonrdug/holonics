## One owner and the actual earlier source

[definition] `enable_material_transport` founds zero coefficients before any material enters an
already enclosed native field. It adds one resident linear transport `T : C^(3N) -> C^N` to that
same owner. The source is the complete coupled outgoing current retained at the actual earlier
source occurrence, with its producing frame and numerical residual source. It is not the raw
endpoint alone and is not recomputed through a later encoder.

[definition] When `y` actually returns through source `j`, the native operation retains the old
forward field `T_j x_j`, computes the contemporary field `T_t x_j`, and carries

```text
returned difference     = y - T_j x_j,
chronological current   = T_t x_j - T_j x_j,
contemporary difference = returned difference - chronological current.
```

The parameter return is `deltaT=(y-T_t x_j)x_j*/(1+||x_j||²)` in the declared unit reference
metrics. The fresh material emission is `T_(t+1) x_(t+1)`. The parameter adjoint uses the retained
source `x_j`; its forward differential is `deltaT -> deltaT x_j`. No current source, new answer,
source filename or expected text substitutes for that operand.

[definition] The encoder reaction, parameter delta and fresh forward field are staged in one
native operation. The final continuing writes occur only after all three return successfully.
The parameter matrix is updated by its staged delta; the ecology is not cloned. A later transport
refusal leaves the old encoder, relation, covariance, coefficient matrix and source available.
Unknown completion retains the existing pending/uncertain state and does not authorize replay.

## Numerical representation and full defects

[definition] The exact transport is represented by a dyadic coefficient centre, a Frobenius error
radius and its retained source-qualified update expression. The device uses integer products and
directed divisions only. A centre is never declared to be the exact coefficient or current.
Source and target current charts use the same declared fractional precision in this first binding.

[proved-derived] Write `H_x=I-x x*/(1+||x||²)` and `k_x=x*/(1+||x||²)`.
The exact update is `F(T,x,y)=T H_x+y k_x`, with `||H_x||<=1` and `||k_x||<=1/2`.
For the rank-one orthogonal projector onto `(1,x)`,

```text
P_x = (1,x)(1,x)*/(1+||x||²),
||P_x-P_z|| = ||(I-P_x)(1,z)|| / ||(1,z)|| <= ||x-z||.
```

The equality follows from the two eigenvalues of the projector difference on the span of the
two generating vectors. The blocks of this projector give the same Lipschitz bound for `H` and
`k`. Consequently, with coefficient error `E_T`, source error `E_x` and target error `E_y`,

```text
||F(T,x,y)-F(T_hat,x_hat,y_hat)||_F
  <= E_T + (||T_hat||_F+||y_hat||) E_x + E_y/2.
```

Existing coefficient uncertainty is not multiplied by a feedback gain. The encoder source error
has its own already retained current certificate.

[definition] The first device bound uses conservative L1 bounds for the displayed norms. These
are numerical error receivers, not language scores or attachment selectors. At scale `S=2^g`,
the gain denominator is rounded upward from `S*(1+||x_hat||²)`. If `n_D` squared-coordinate
roundings occur, the denominator contribution to gain error is at most `n_D/(2S)`; directed gain
division adds its own counted coordinate errors.

[proved-derived] Let `E_p` bound the numerical old-source matrix contraction, `E_k` bound the
numerical gain relative to `k_(x_hat)`, and `E_mul` bound the product rounding. The numerical
parameter-return defect obeys

```text
E_num <= E_p/2 + ||r_hat|| E_k + E_mul,
r_hat = y_hat - prediction_hat.
```

The native coefficient bound adds this quantity to the source/target bound above. A new forward
field has error at most

```text
E_Tnew (||x_hat_new||+E_xnew) + ||T_hat_new||_F E_xnew + E_dot.
```

All integer charges are rounded upward in their declared grid quanta.

[definition] The retained update stores its two numerical factors, their denominator and bounds,
old/current forward fields and complete oriented differences. The exact coercive proposal is
rank one; the rounded matrix need not be. Its deterministic product residual is retained by an
executable factor expression. `inspect_material_transport_residual` reconstructs the complete
oriented parameter-update, source-contraction and gain defects before a norm projection.

[definition] `inspect_exact_material_transport` evaluates the retained encoder residual trace
and source-qualified coefficient expression at an explicitly requested historical cut. It checks
the exact coefficients and forward fields against their native balls. It performs no native event,
model update or source-handle creation. Its rational work grows with the requested cut. Product
