## Representation and residual

[definition] At a declared fractional precision `g`, a report carries dyadic numerical centers
`V,H,P,U` and Euclidean radii, all in the root current chart. Centers are integer grid coordinates
at scale `S=2^g`; they are not asserted to be the unique physical currents. The full signed numerical
residual and the exact source chart remain retained alongside the radii:

```text
delta_u = u - U/S
r = A(V/S) - 2(U/S + H/S)
e_h = h-H/S.
```

[definition] Integer LDL factorization proposes `V`; exact residual evaluation certifies it against
the original `C`. Factorization uses wide integer centers and full 256-bit products before directed
division. There is no float, semantic score, midpoint current seal, hidden clipping or approximate
current supplied to moment formation. A representation whose arithmetic cannot return refuses
before the native successor commits.

[proved-derived] Since `C` is positive semidefinite, `A` is positive definite and
`||A^-1|| ≤ 1`. For `B=I-2A^-1`,

```text
I-B*B = 4 A^-1 C A^-1 ≥ 0,
```

so `||B|| ≤ 1` and `||I+B|| ≤ 2`. Consequently the actual errors obey

```text
e_v = 2 A^-1(e_h+delta_u) - A^-1 r
e_out = 2 A^-1 e_h - B delta_u - A^-1 r
e_h_next = B e_h + (I+B)delta_u + A^-1 r.
```

The inverse bound follows from `⟨x,Ax⟩≥||x||²` and Cauchy–Schwarz; the displayed positive quadratic
form proves the contraction bound directly. These are bounds for the declared junction, not a
generic nonlinear ecology or a language-quality claim.

[proved-derived] If integer quanta `E_h,E_u,R` bound the old Euclidean error, ingress error and
`S||r||₁`, the triangle inequality and `||r||₂≤||r||₁` give

```text
E_v     = 2 E_h + 2 E_u + R
E_out   = 2 E_h + E_u + R
E_hnext = E_h + 2 E_u + R
E_Pnext = E_P + E_v.
```

The new centers are `V-U`, `2U+H-V` and `P+(-1)^t V`. Existing error is not multiplied by a
coordinate-box norm at every occurrence. The native ingress bound counts nonexact coordinate
roundings, each of magnitude less than one grid quantum; it bounds numerical error and selects no
contact, coefficient or answer.


Each later row `L[i,k]` reads only those inputs and its own original upper entry, and writes a
