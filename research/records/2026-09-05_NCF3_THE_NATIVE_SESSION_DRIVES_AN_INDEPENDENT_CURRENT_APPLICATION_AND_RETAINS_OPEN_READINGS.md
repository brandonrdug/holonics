the application was graded. An exterior system owns fixed complex couplings `c_j`, rotation

uncommanded. Its independently accumulated unactuated control always advances by `rho*u+m`.
The actual sensor response returns through the emitted source handle as ordinary native input.
No world routine can inspect or write the developing paired basis or fit its own predictor.

## Position

[established-bounded; measured] NCF3 is complete at this native-interface and independent
linear-current application scope. The output is inspectable and usable through the public
framework, and the application contains no fixture-private learner.

[open] NCF4 remains. It must preserve the actual native relation, held phase, current and
historical frames/material, emitted-source populations, receiving lineage and outstanding
linear handles. The exterior handle table must be serialized separately from native ordinals;
the stream needs its pending bytes/cursors; the application needs world state and any already
enacted effect/pending receive. Process-separated further development and cold/warm, locality,
residency, transfer and latency evidence must agree with the declared continuation family.
This phase does not complete the corrected goal or resume inherited-model/export construction.
