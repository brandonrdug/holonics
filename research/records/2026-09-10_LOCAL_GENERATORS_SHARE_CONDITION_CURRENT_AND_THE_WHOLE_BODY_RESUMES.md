## The declared object and return

[definition] `ResidentGeneratorNeighborhood` owns local `ResidentConstitutiveFibre` laws, one
actual `ResidentConditionCurrent`, an occurrence epoch and the latest received condition evidence.
The constructor explicitly declares that the local laws share this condition chart. Each learned
law determines its dependence on that field. Co-membership adds no interaction coefficient or
all-to-all inference. The current implementation requires matching bilinear source/condition
charts and a common resident surface; local output widths may differ.

[definition] For local relation R, supplied source x and observed return y, the existing preimage
owner derives F = {c | (Phi(x,c), y) belongs to R}. For nonempty F = a + V, the existing declared
unit-admittance contact returns h' = P_V h + (I-P_V)a. The actual prior current h supplies the
unmeasured component. This does not select an external cause from F. Empty F retains h and the
old relation's obstruction; ordinary local material formation can then extend that relation.

[definition] An observed neighborhood passage performs these dependent operations:

1. Read the old receiver family using the actual prior current.
2. Derive the compatible condition family and prepare contact into fresh resident sections.
3. Use the proposed current in the existing observation-founded local relation formation.
4. Publish the prepared current, latest evidence and epoch only after that return succeeds.

[definition] The returned step borrows the actual source/observation and shares immutable prior
condition standing. It contains the predecessor prediction, contact and material return. It is
not a recomputed prediction falsely attributed to the predecessor. Subsequent `read` uses the
new current. No received current means a read and neighborhood epoch advance, without material
deposition. This is the same local relation law, not a second training algorithm.

[definition] Prepared contact binds the actual predecessor section and contact count. Equal
numeric values in another owner cannot authorize commit. Exclusive ownership preflights the
current before the local law's only mutation; publication afterward has no fallible device step.
Known precommit refusal preserves both law and current. Uncertain device completion makes the
neighborhood unusable rather than permitting a partial replay. No whole live body is cloned.

## What rests, and what does not

[definition] `GeneratorNeighborhoodRest` stores each compact learned relation, actual condition
current, epoch, and one latest received condition constraint. `ConditionPreimageRest` stores its
constraint generator and right-hand side. The existing native relation query decodes the full
affine fibre on remount; there is no duplicate solved family in the wire. This decoder performs
constraint evaluation, not source observation replay or further learning.

[definition] Latest evidence retains its member and producing predecessor-law cut. It is replaced
by the next received event. It is not asserted to be the intersection of every historical world
observation or a cumulative posterior. If old evidence was outside the represented relation,
formation can extend that relation while the retained evidence still records the original
obstruction. Changing this scope would require an actual transport/refinement law.

[definition] `ConditionCurrentRest` preserves current numerators and their original denominator.
Remount initializes unused contact-report slots as a stationary mount frame; it does not invent
the previous contact's normals or reconstruct the full passage. The source apparatus, its
diagnostic history, original source populations, and past step objects are absent from this
model rest. Epochs and law cuts are chronology, not learned contact coordinates or source identity.
