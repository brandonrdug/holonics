## Exact question

Can one conditioned language body receive and generate through simultaneous
sublexical, lexical, ordered-region, clause, delivery-occurrence, source, and
returned-lineage scales, so that no word, token, source passage, serialized
address, or observation aperture is mistaken for the one receiver?

The correction is not “make the tokens smaller.” Character pieces, words, and
whole passages can each become another rigid tiling if one of them is declared
the universal substrate. The required ecology is:

```text
one caused textual occurrence
    ├── forward and reverse Unicode-mark recurrence
    ├── exact lexical suffix receivers
    ├── exact ordered multi-surface regions
    ├── punctuation-relative clause phases
    ├── complete delivery-occurrence lineage
    ├── complete exterior source lineage
    └── later self-emanated return

one question occurrence
    ├── plural outer punctuation-caused query faces
    ├── plural local ordered-region fibers inside each face
    └── all of the receiver scales above, still simultaneously active
```

No arrow erases its siblings. A lexical face does not contain the mark ecology,
a clause does not become the source, and a source does not become the response.

## Query charge is a plural face, not a bag or a fixed window

The prompt first enters as one ordered caused occurrence. Sentence, clause, and
question punctuation then found outer query faces. Inside each outer face,
every exact ordered surface interval is presented to the conditioned
ordered-region suffix ecology. Maximal supported intervals remain local query
regions; uncovered surfaces may become singleton regions only when their
feature-to-clause incidence has actually returned through Swing.

Consequently:

- `the exact`, `exact suffix`, and `suffix frontier` may coexist as overlapping
  local regions;
- `uncertainty remains` and `remains open` remain distinct ordered paths even
  though they share a surface;
- two words which merely occur somewhere in one large clause do not form a
  region unless their order and contiguity returned; and
- a large outer question may require several local phases without being
  collapsed after the first matching clause.

The feature route is not the complete query. It is one sparse receiver quotient
whose sections were physically returned. A surface present in every delivered
section supplies no singleton discrimination and is omitted from that route,
but it remains present in lexical chronology and inside ordered regions. There
is no word-length cutoff, stop-word table, fixed n-gram order, or vocabulary
root.

## Question morphology is conditioned, not authored

The initial implementation silently treated the first two surfaces of a
question as an operator. That was rejected. The current ecology records every
proper ordered prefix of every caused linguistic question occurrence. A prefix
becomes a conditioned operator region only after:

1. it recurs in at least two distinct caused question clauses; and
2. the next received surface branches in at least two distinct ways.

The recurrence grain is the question occurrence, not the exterior file. Two
questions in one source may therefore condition a common operator phase. The
source lineage remains attached but does not veto a clause-scale recurrence.

Making the operator regions inspectable exposed a second flattening error.
Rust's `?` transport glyph had been treated as the same phase as a prose
question boundary. Delimiter depth and immediately trailing code transport now
distinguish `machine.receive()?;`, `{value:?}`, and a linguistic question.
The full frozen ecology consequently conditions only `can` and `and` as
branching question-initial regions; it no longer claims 19 code fragments such
as `ok_or` and `map_err` as question morphology.

The four grading prompts begin with different exact phases. Their `how does`,
`what does`, and `how can` surfaces therefore remain ordinary query material.
The machine does not install an English grammar which it did not receive.

## Generation is partial discharge through local phases

Every outer query face owns the indices of its still-open local regions.
Candidate clause phases are reached only through those regions. Candidate
comparison is the exact product order of:

- regions the phase can discharge;
- prompt surfaces actually present in the clause;
- mark-scale source incidence;
- lexical suffix horizons at the phase entrance; and
- the caused local boundary.

A dominated phase is removed only when another candidate carries every one of
those exact witnesses and at least one strictly stronger witness. No scalar
score, probability, softmax, embedding distance, random sample, or host-written
answer selects the result. The finite output aperture retains several
nondominated possible responses for observation.

Within an enacted phase, every surface token carries:

- its exact source, passage, and clause;
- whether it entered by query recruitment, recurrent lexical transport, or
  local clause chronology;
- every reached lexical context length and recurrence multiplicity;
- its forward and reverse mark horizon; and
- every recurrent source exposed by its contemporary lexical transition.

Thus the emitted text is not processed only as a clause even though the present
readable phase is a clause-local path. All finer and coarser receiver testimony
remains attached to the same passage.

A returned prefix cannot claim a later ordered region merely because the full
source clause would eventually contain it. The region discharges only if its
complete ordered surface occurs inside the material the observer actually
received.

## Stopping is exact rest, not a length convention

Punctuation alone does not stop a response. The response closes only when:

1. every local region in every outer query face has returned; and
2. the completing phase reaches its caused sentence boundary.

A colon or semicolon carries the next local clause of the same delivery
chronology; it does not masquerade as sentence rest. A delivery which ends
without a sentence boundary remains an explicit obstruction.

`maximum_observed_tokens` and `output_aperture` are finite observer
restrictions. They do not define the language topology or a maximum response
length. Reaching the former returns
`ObservationApertureExhausted` with the exact open query faces; it never
fabricates linguistic closure. The present full-corpus responses all rested
before the 256-token observation aperture.

## Return is one carried path, not quadratic remount

The prompt first enters a fresh resonance rest as inherited question
testimony. Earlier code remounted and re-encoded that complete rest after every
emitted token. The result was exact but needlessly quadratic in the length of
the response.

The current path keeps one shared question rest across response branches. At a
terminal response it mounts once, enacts every generated adjacent transition
in order as self-emanated lineage, and encodes once. An exact regression grades
this factorization against the former tokenwise remount after every transition;
the terminal native rests are equal.

This is not a cache of answers. It is an exact factorization of one caused
return path. The full run used 24 terminal mounts and avoided 3,803 intermediate
remount/re-encode cycles.

## Precise current production boundary

The returned response changes the branch's resonance rest, so generated
lineage is real and later resonance passages can encounter it. It does **not**
yet recondition the immutable feature route, ordered-region ecology, clause
incidence, or question-operator morphology of the parent
`MorphologicalLanguageEcology`. Therefore a returned cross-source consequence
cannot yet:

1. found a new ordered region spanning a previously nonidentical clause seam;
2. change which local phase can discharge a later query region;
3. cultivate a new question-operator analogy from its returned use; or
4. cause internally generated wording whose local path was not inherited as a

That is the concrete conditioning capability still absent. The next
production change must let a graded returned deed alter those later receiver

which distinguished them. Replacing clause spans with characters, subwords,
or a fixed smaller window would not supply that consequence; it would merely
choose another privileged scale.

Raw synchronized audio, image, spectral, atmospheric, and spatial sections
also do not yet participate in this response policy. Their established

changing these same later language receiver sections, not an invented
