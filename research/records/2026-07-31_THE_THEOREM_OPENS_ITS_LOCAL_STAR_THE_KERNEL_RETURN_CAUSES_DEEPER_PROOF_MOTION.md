# The theorem opens its local star; the kernel return causes deeper proof motion

Date: 2026-07-31

## Ratified question

The requested deed was not another language sample, visualization, topology count, or proof that
Eros can condition at all. The question was whether the continuing machine could receive the
repository's formal Lean mathematics, retain an operative mathematical morphology after the
developmental sources departed, compose a proof of a useful theorem which neither occurred in
those sources nor arrived with a supplied proof, and return the emitted proof to Lean itself.

The production owner is `life::lean_mathematics::LeanMathematicsEcology`. The inherited world
codec is Lean's parser/elaborator/tactic/kernel environment. The emitted consequence is complete
Lean source accepted by that kernel. The examples are grading membranes around that production
owner; they do not own proof generation.

## Face, codec, conditioning, and return

A Lean document is a structured face, but its bytes are not self-reading. The inherited Lean
language, project imports, notation, elaborator, tactics, and kernel are codecs. Eros does not
claim to have induced those codecs from repository text. Four proof-motion organs are mounted and
named as inheritance: direct application, goal rewrite, local-fact introduction, and hypothesis
contraposition.

The repository documents then cross as developmental material. Conditioning retains a native
incidence body of declaration identity, source lineage, explicit/implicit binder charts,
statement-identifier incidence, inter-declaration proof references, and encountered tactic
species. It retains no theorem statement or proof surface. The clean collector excludes `.git`,
`.claude`, `.lake`, `target`, and `runs`, so hidden worktrees, compiler output, and earlier grading
artifacts cannot silently train the body.

Mounting and training have distinct consequences. The mounted codec-only body reaches no local
declaration for the held-out theorem. After the Lean passages return through `train`, the same
body emits a plural proof family. Its developmental documents then depart; exact native remount
preserves the same family. This before/after/source-departed regression is part of the production
module rather than an assertion in the report.

The retained proof ecology from this run contains:

- 88 clean Lean documents and 1,327,292 exposed source bytes;
- zero retained source surfaces;
- 1,164 declaration organs, 2,072 binder charts, and 2,625 declaration-reference relations;
- fourteen encountered tactic species;
- a 724,208-byte exact native body with SHA-256
  `e7472740029f3d8dff6140213105c0690e88e459977998e8b515ed380c02ba2a`;
- byte-identical native remount.

Candidate ordinal, compiler latency, and diagnostics do not score or rank proofs. Every complete
path in a caused round crosses Lean. Acceptance is exact return testimony; failure remains an
obstruction. If every one-organ path fails, that complete return causes the next round to compose
two declaration organs. This is proof motion responding to world return, not a fixed final answer
selected from a stored passage.

## First generated theorem: a local transport overload becomes physical excess

The target theorem and its proof were both absent from every conditioning document:

```lean
theorem proportionalFlow_exceeds_capacity_of_subset_overload
    (hd : ∀ n, 0 ≤ demand n)
    (hc : ∀ m, 0 ≤ capacity m)
    (hz : ∀ n, descendantCapacity capacity incident n ≠ 0)
    (S : Finset Old)
    (m : New)
    (hinc : ∀ n ∈ S, incident n m)
    (hcapacity : 0 < capacity m)
    (hover :
      1 < ∑ n ∈ S, demand n / descendantCapacity capacity incident n) :
    capacity m <
      ∑ n : Old, proportionalFlow demand capacity incident n m
```

Its meaning is useful to the source-transport programme: a subset whose exact normalized demand
already exceeds one and whose members all meet receiver `m` forces the total proportional current
entering `m` to exceed `m`'s positive capacity. It turns a quotient-normalized congestion witness
into a strict receiver-local flow obstruction.

Eros emitted this primary proof:

```lean
by
  rw [proportionalFlow_column_sum]
  have generated := congestion_exceeds_one_of_subset_load demand capacity incident hd hc hz S m hinc hover
  nlinarith
```

The first round graded 86 one-organ paths and every one failed. That complete obstruction caused
84 pairwise compositions. Exactly two closed. The second accepted path replaced
`congestion_exceeds_one_of_subset_load` with the weaker
`subset_normalized_load_le_congestion`; it therefore witnesses a genuinely plural proof fiber,
not an ordained stored answer. In total, 170 paths were generated, 168 were obstructed, and two
were kernel-accepted.

The causal lineage of the primary proof is exact:

1. `proportionalFlow_column_sum` rewrites incoming current into capacity times congestion;
2. `congestion_exceeds_one_of_subset_load` supplies strict congestion from the subset witness;
3. `nlinarith` closes the resulting ordered-ring consequence using positive capacity.

## Second generated theorem: global excess must appear at a local receiver

The second target asks for the converse reading of the existing conservation theorem. If total
demand exceeds total capacity, some receiver must have congestion above one:

```lean
theorem exists_overloaded_receiver_of_total_demand_exceeds_capacity
    (hc : ∀ m, 0 ≤ capacity m)
    (hz : ∀ n, descendantCapacity capacity incident n ≠ 0)
    (hover : (∑ m : New, capacity m) < ∑ n : Old, demand n) :
    ∃ m, 1 < congestion demand capacity incident m
```

Eros emitted:

```lean
by
  contrapose! hover
  exact total_demand_le_total_capacity demand capacity incident hc hz hover
```

One of 65 returned local paths closed. This proof performs a logical chart change: contraposition
turns the existential overload goal into the all-receivers congestion bound required by
`total_demand_le_total_capacity`, then transports that changed hypothesis into the conserved
finite system.

This experiment also returned a real codec correction. The initial binder parser treated the
summation coordinate in `(∑ n : Old, demand n)` as if it were a theorem argument. Lean rejected
the malformed application because the congestion hypothesis had not been transported. The
parser now stops declaration-binder acquisition at the top-level result colon; expression-local
indices remain inside the theorem face. A dedicated regression requires the transformed target
hypothesis to rebind the unmatched source hypothesis.

Both generated files were independently passed through `lake env lean`. Both report only
`propext`, `Classical.choice`, and `Quot.sound`, the axioms inherited through this mathlib project;
neither contains `sorry`, `admit`, or `sorryAx`.

## What this establishes

This is the first production-owned formal-mathematics generation path in Eros. It establishes
all of the following together:

- repository-scale Lean conditioning with exact source departure and remount;
- target-relative recruitment of a plural local declaration star;
- new-to-the-corpus proof composition in familiar formal notation;
- an exact compiler obstruction causing a deeper composition round;
- retention of alternative valid proofs rather than premature argmax selection;
- final truth adjudication by Lean's kernel rather than assistant prose or a scalar score.

It is stronger than passage retrieval: no theorem/proof surface is retained, both complete proofs
are absent from the exposed corpus, and the accepted local proof combines two declarations plus a
closure motion. It is also stronger than a hard-coded example: the production ecology accepts an
arbitrary `LeanProofProblem`, source scope, project world, and conditioned declaration body.

This does **not** establish field-novel mathematics, arbitrary Lean theorem proving, an RH proof,
or an induced Lean language. The theorem headers were supplied as questions. The current
declaration morphology retains binder and incidence structure but not a fully elaborated
dependent-type expression graph, and its mounted proof motions are a small inherited grammar.
Consequently its present competence is exact local-star proof composition, not unrestricted proof
planning across definitions, induction schemes, auxiliary lemma invention, or long dependent
proof states.

The concrete production frontier is therefore specific. A richer organ must retain elaborated
type-expression incidence without retaining source surfaces; Lean diagnostics must return typed
unsatisfied goals into the continuing proof body; and those returned goal fibers must be able to
found auxiliary statements, reuse a declaration more than once, branch through constructors and
induction, and later alter subsequent proof motion. Coupling that organ to the existing
conversation-conditioned `AgenticLanguageEcology` would then let Eros formulate and discuss its
own formal questions, but the accepted Lean deed—not its prose—must remain the grading authority.
