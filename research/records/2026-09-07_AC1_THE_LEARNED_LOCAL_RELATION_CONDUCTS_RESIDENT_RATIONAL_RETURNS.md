## The concrete missing port

[established-bounded; source-inspected] The previous `ResidentConstitutiveFibre::advance` accepted
host integer arrays, mounted them, executed the native relation and read its numerical result on
the host. The resident basis already retained a domain and vertical fibre, but the public return
could not itself enter the next native operation as a rational current. A learned relation was
therefore usable through that observer boundary rather than directly composable on the device.

[definition] The new `advance_resident` accepts borrowed current sections and an optional actual
receiving section. An integer section can come from exterior ingress or a native producer. An
immutable `ResidentConstitutiveReturn::current` carries the previous output's rational numerators,
denominator and disposition into the next device operation. Host code addresses and schedules
these sections; it does not inspect numerical values to determine a current or deposit.

[definition] The law remains the existing local rational-linear relation. If the source is
`s = ns/ds` and the actual reception is `y = ny/dy`, the kernel forms the common-denominator row
`(ns*(lcm/ds), ny*(lcm/dy))`, with `lcm = lcm(ds,dy)`, and uses the existing `fibre_stage`.
It queries the predecessor with numerator `ns` and denominator `ds` through `fibre_query`.
This is the same graph-span construction as the earlier integer mouth. It admits future currents
in the observed source span while leaving other source directions open; a full unknown operator
need not be identified before such a current conducts.

[definition] All pointness, positive-denominator, original-disposition and overflow checks precede
the single continuing basis write. The receiver's immutable return includes the original vertical
direction basis. A later deposit cannot rewrite that earlier face. This is a compact consequence
of the relation, not a clone of the ecology or an archive of raw sources. The original integer API
and the resident API operate on the same move-owned basis.

[definition] A borrowed point-current aperture requires a unique response. This hypothesis is
checked on device when a returned current is consumed. An outside-domain or plural return stays
available with its actual face; the point consumer refuses instead of passing along its particular
solution as a selected answer. The broader task of conducting a whole relation through a
relation-valued port remains distinct from this point-current attachment.
