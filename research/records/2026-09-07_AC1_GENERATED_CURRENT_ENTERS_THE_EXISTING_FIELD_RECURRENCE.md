## Input and successor

[definition] `NativeConstitutiveField::advance_current_resident` takes the same entering,
linear-emission or shared-anchor occurrence with an empty exterior input vector, plus a borrowed
`ResidentConstitutiveCurrent`. The explicit resident port supplies the actual root receiving
current. Concurrent exterior and resident inputs refuse; neither silently overrides the other.
The existing source-owner, source-consumption, historical-frame and pending-operation checks apply.

[definition] `section_field_current_input` in `constitutive_field.cuh` checks the current's point
and denominator contract and packs its real/imaginary coordinates into the field's per-node
rational triples. The denominator is normalized on the device. A second dependent lane conducts
the ordinary field operation, including its paired junction, internal current, material return
and source consumption. Both lanes belong to one passage. No host phase calculation, numerical
readback, codec conversion or alternative learning law produces the successor.

[definition] A malformed, foreign, plural or out-of-domain point-current view refuses. An actual
current from the retained condition owner has its own point contract, including when condition
evidence remains plural or empty. Thus the point-input contract does not make condition
identification a universal prerequisite for generation. Known input refusal preserves the old
field and the original source capability. Unknown completion retains the ordinary pending field;
the new entry does not introduce rollback or replay.

## Actual input lineage and cold storage

[definition] `NativeFieldIncoming` distinguishes exterior values from resident input provenance.
Exterior values retain their previous JSON array representation. A resident declaration records
its node extent; the actual input values reside in an immutable historical section. The metadata
is not those values, and equal metadata does not identify two inputs. `inspect_incoming` is the
explicit cold receiver for their actual values.

[definition] Resident history, `HeldRest`, the field rest reader/writer and the append-only
history archive retain the extra input section. The archive's existing transport-presence byte
now uses its second bit for input presence; old bytes retain their original meanings. The field
rest's input declaration determines whether an input section follows its historical transport.
Validation requires the declaration and carrier to agree, with exact normalized phase words.
This extends the existing field history realization; it is not a new general requirement to
archive every raw state in order to learn or recover a generator.

[definition] Cold internal-current and material decoders use the actual input carrier through
`inspect_incoming`. `NativeCurrentHistorySourceReceiver` instead borrows that carrier directly
for its hot prefix operation. It performs no numerical read/remount when the input was resident.
The additional retained input payload is `3*N` exact word pairs, or `48*N` bytes, for each such
historical occurrence before exterior placement. Current placement, chronology and obstruction
remain those of the existing field owner.
