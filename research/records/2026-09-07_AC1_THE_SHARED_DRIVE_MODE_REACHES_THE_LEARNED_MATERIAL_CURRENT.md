## Source and operator cuts

[definition] Let `l,r` be two native-admitted shared-drive contacts, `q_s=b_l(s)-b_r(s)`, and
`m=(e_l-e_r)/2` in the complete source's internal coordinates. Both contacts must have been born
at the requested actual source `s`. For a material operator `M_t`,

```text
x_s = m q_s + (x_s - m q_s)
M_t x_s = (M_t m) q_s + M_t(x_s - m q_s).
```

The preceding record derives this orthogonal decomposition. Its remainder is preserved; this
does not replace the full source by one scalar mode or assert that a projected source is a
separately executed ecology.

[definition] `read_material_mode` uses an actual source anchor. `read_material_mode_at` is its
read-only body-local address form. `read_material_mode_using` reuses the same immutable admitted
mode as its original field continues. A runtime-only owner token prevents a mode from indexing
another field's internal columns. The standalone mode wire and its source-independent unfolding
remain unchanged; a standalone/imported packet does not acquire such an in-body identity from
matching occurrence numbers.

[definition] The return records the source occurrence, producing operator `M_s`, contemporary
committed operator `M_c`, both birth histories and any actual latest reception from that source.
The mode's own capture cut is separate and its phase is transported to `s`. A later operator
read does not rewrite an earlier prediction. An observed target belongs to the whole source;
the receiver does not manufacture a separate target for the mode.

## Existing factors supply the coefficient

[established-bounded; source-inspected] The fused complete material return retains each numerical
update factor `beta_i` and its actual source `a_i`. Its numerical operator is
`Mhat_t = sum_(i<=t) beta_i xhat_(a_i)*`. The existing receiver for an older source evaluates these
immutable factors; it does not repeat their formation. The new kernel reuses the same factors,
prefix carriers, source refresh and global coefficient-error bounds.

[proved-derived] Linearity gives

```text
Khat_t = Mhat_t m = (1/2) sum_(i<=t) beta_i conjugate(qhat_(a_i)).
```

For a source before both births, the absent internal coordinates are zero, so its term vanishes.
For a source between the births, the present contact contributes its actual numerical prefix
contraction, with the right contact carrying a minus sign if only it exists. After both births,
the shared current prefix cancels and the mode generator supplies `qhat_(a_i)` by its original
amplitude and relative phase. These are distinct source domains; extrapolating a completed mode
back before its births would give the wrong coefficient.

[definition] The kernel reads factors in their original chronological order and separates those
at or before `s` from the later factors through `c`. It returns `K_s`, `K_c`, their change, both
mode images, both remaining images, both full images and their full change. When the latest
actual receiving occurrence names `s`, it also retains the observed whole receiving current and
its difference from the original full prediction. The contemporary map is the committed map
after that receiving operation; it is not silently substituted for the map used before its return.

## Numerical fibres and executable use

[proved-derived] Suppose the native complete-map bound is `||M-Mhat||_F <= E_M` and the mode
amplitude lies in `B(qhat,e_q)`. Since `||m||=1/sqrt(2)<=1`, the coefficient error is at most
`E_M`. For `K=M m`,

```text
||K q - Khat qhat||
  <= E_M (|qhat| + e_q) + ||Khat|| e_q.
```

Expand the difference as `(K-Khat)q + Khat(q-qhat)` and apply the triangle inequality and the
operator norm bound to obtain the displayed inequality. Native outward rounding is added to
this bound. Coefficient and current differences use the appropriate two map-error bounds;
when no admitted factor can change these columns, the common error cancels instead. Columns
whose sources all predate both births remain exactly zero. Remaining-current bounds follow
from the full-minus-mode decomposition and the triangle inequality.
