## Retained owner and application boundary

[established-bounded; source-inspected] `constitutive_fibre/field/rest.rs` owns the complete cold
field chart: current primary seed and held memory, linear relation, contact covariance, current
junction, learned material coefficients, all raw source/junction/transport history, frame and
incidence chronology, and explicitly supplied live source/anchor slots. The last historical
junction and the current junction share one resident section on remount. The empty case retains
its actual initial section. No dropped linear capability is regenerated from an unreturned flag;
duplicate linear slots and foreign handles refuse. Shared immutable anchors may recur.

[definition] `NativeFieldRest` is an exterior chart, deliberately without `Clone`. `remount`
consumes it, installs its complete sections and creates one new move owner; it does not enact
old occurrences or recompute old learning on the host. Structural validation checks extents,
frames, lineage, consumption, rank receipts, complex covariance form and numerical wire bounds.
It does not certify that an externally authored developmental history actually happened.
The compact section wire stores each exact i64 codeword once and reconstructs its two identical
interval endpoints. Packed wide integers, current radii, oriented residuals and histories survive
unchanged. This removes redundant wire endpoints, not a semantic fibre.

[established-bounded; source-inspected] `holonics-hna::alpha::checkpoint` composes that field rest
with actual text source capabilities, staged input, shared parent anchors, opaque application
bytes and existing `HnaStreamState`. Its separate native text artifact kind uses the existing
atomic no-overwrite publication and wire integrity helper. Live clients supply their actual
delivery state through `checkpoint_stream`; the batch helper declares empty delivery state.
The reader checks the envelope before mounting native sections. An uncertain native launch
refuses persistence rather than declaring which successor happened.

[established-bounded; source-inspected] `alpha_text --checkpoint` saves development before an
optional prompt. Its application chart binds the cold exposure cursor, actual completed/partial
records and family-to-native-anchor population to that native cut. `--resume --families N` mounts
it and admits N additional development families. Zero additional families never opens the source
reader. Partial input retains its actual symbol/source and source coordinate for retry; another
symbol cannot overwrite it. The batch driver refuses a nonempty saved delivery state and a
requested numerical grain change. The SDK exposes saved live delivery without that restriction.
