# Research reading routes

Use these routes to recover the construction behind a term before selecting an implementation.
Each starts with a maintained guide, then a few source records and the owners they connect.
They are reading paths, not phases or an inventory of every file. The
[machine](../../docs/THE_MACHINE.md), the [elementary objects](../../docs/ELEMENTARY_OBJECTS.md),
[the rebuild](../../docs/plans/THE_REBUILD.md) and the [current state](../../CONSTRUCTION_STATE.md)
give the overall object and active operation.

Records are dated history. Many name code retired at the September 24 reset; that code is in
history at [`13f8c734`](https://github.com/brandonrdug/holonics/tree/13f8c734), and a record's
law is ported from there only when a rebuild step needs it. Record titles keep their original
wording ("generator", "session"); read them through the elementary objects, where the object is a
navigator and time is an aeon divided into epochs. For another spelling or a deeper branch:

```bash
rg -n '<term>' docs research lean crates
git grep -n '<term>' 13f8c734 -- crates docs
```

## Maintaining a route

A new record keeps its dated filename. Add it to the relevant route when it changes a reusable
law or supplies the source needed by an active consumer; retain the earlier record and explain the
new scope. Update the subject guide and code link as well. To find a relation outside these
starting paths, search its ordinary, formal and native spellings, then read the named source.
This page grows by useful connections rather than by reproducing the entire file inventory.
