[machine](../../docs/THE_MACHINE.md), [roadmap](../../docs/plans/THE_ROADMAP.md) and

## Maintaining a route

A new record keeps its dated filename. Add it to the relevant route when it changes a reusable
law or supplies the source needed by an active consumer; retain the earlier record and explain the
new scope. Update the subject guide and code link as well. To find a relation outside these
starting paths, search its ordinary, formal and native spellings, then read the named source.
This page grows by useful connections rather than by reproducing the entire file inventory.
