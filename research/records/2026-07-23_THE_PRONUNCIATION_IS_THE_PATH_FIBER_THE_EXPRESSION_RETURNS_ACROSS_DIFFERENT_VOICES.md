## Theory-to-structure relation

For one utterance `x`, the inherited CTC source supplies a finite field

```text
A_x = {a_(t,k) : frame t, alphabet symbol k}.
```

Each `a_(t,k)` is the exact nonnegative dyadic represented by one returned IEEE-754 binary32
codeword. It is inherited finite machine material, not an assertion that a binary float is an
ontologically real probability.

For an expression `y=(y_1,...,y_m)`, insert blanks:

```text
ell(y) = (blank,y_1,blank,...,y_m,blank).
```

The exact forward relation is

```text
alpha_(0,0) = a_(0,blank)
alpha_(0,1) = a_(0,y_1)

alpha_(t,s) =
  a_(t,ell_s)
  * (
      alpha_(t-1,s)
      + alpha_(t-1,s-1)
      + skip(s) alpha_(t-1,s-2)
    ),

skip(s) = 1
  exactly when ell_s is not blank and ell_s != ell_(s-2).
```

Missing indices contribute zero. The complete fiber measure is

```text
M_x(y) = alpha_(T-1,2m) + alpha_(T-1,2m-1).
```

This recurrence sums every CTC path whose blank/repetition collapse is `y`; it does not select one
alignment, one attention edge, one nearest neighbor, or one threshold crossing. Because every
source word is an exact dyadic, every multiplication, addition, comparison, and returned residual
is integer arithmetic over a power-of-two denominator.

The complete alphabet field, the fixed recurrence law, every candidate expression fiber, their
exact order, and the winning/nonwinning residuals remain in the observation. The greatest fiber is
one declared receiver quotient used to afford a present expression face. It is not the identity of
the utterance and does not erase the rest of the field.
