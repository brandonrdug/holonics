## 4. The returned path is not exact and not a certified final enclosure

**Truth status: counterexample.**

RMS roots, rotations, GELU, and exponentials are represented as local intervals. The implementation
then:

1. propagates the interval midpoint as though it were exact;
2. stores the local half-width in a side population;
3. feeds only the midpoint to successor operations.

A local remainder that is “exhibited, not propagated” does not certify a nonlinear composite.
Successor contractions, products, radicals, exponentials, and residual joins must receive the
uncertain section or an exact symbolic carrier. Otherwise the final midpoint is:

- not the exact source value;
- not proved to enclose the source value;
- not reconstructible merely from an unordered population of local widths.

The active return is exact rational arithmetic over selected midpoint approximations.

### The contact quotient is unsound for negative carried values

At the contact value transport, numerator interval \(N=[N_-,N_+]\) and positive denominator
\(D=[D_-,D_+]\) are divided as

\[
Q_-=\frac{N_-}{D_+},
\qquad
Q_+=\frac{N_+}{D_-}.
\tag{A.1}
\]

That rule requires an appropriate nonnegative numerator hypothesis. Carried values can be negative.
For

\[
N=[-2,-1],
\qquad
D=[1,2],
\]

the true quotient is

\[
[-2,-1/2],
\]

while (A.1) gives

\[
[-1,-1].
\]

The fallback replaces an inverted enclosure with the lowest carried value instead of repairing the
interval law. The contact result is therefore not a certified softmax/value-transport enclosure.

### Authored approximation levels remain semantic

The path uses:

- **ROOT_OCTAVES = 44**;
- **ROTATION_OCTAVES = 40**;
- environment-selected **TERMS**, default 20;
- **CARRIER_REACH = 46**.

The authored-level ledger itself says the first two should be derived from the carried chart.
These values affect semantic outputs and no complete final receiver-bound derivation makes them
lawful.

## 5. RMSNorm was classified incorrectly

**Truth status: counterexample.**

The source declares

\[
\epsilon=10^{-6}.
\]

For

\[
R_\epsilon(x)
=
G\frac{x}{\sqrt{x^\top x/d+\epsilon}},
\tag{A.2}
\]

nonzero epsilon and nonzero gains retain radius analytically. Removing gain and defining

\[
y=\frac{x}{\sqrt{x^\top x/d+\epsilon}},
\qquad
q=\frac{y^\top y}{d},
\]

we recover

\[
x=
\sqrt{\frac{\epsilon}{1-q}}\,y.
\tag{A.3}
\]

Thus Gemma RMSNorm is not exactly a magnitude-deleting horizon. It is a bounded radial chart. A
projective receiver may deliberately ignore the radius; the exact source operation does not.

The current implementation manifests epsilon but types the operation as **RebaseByGain** and does
not return:

- source radical as a propagated algebraic section;
