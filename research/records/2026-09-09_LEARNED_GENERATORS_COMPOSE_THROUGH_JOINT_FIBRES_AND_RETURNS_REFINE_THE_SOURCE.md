## The composed object

[definition] Let R be the retained local linear relation in V × W and F = a + U an affine
current family returned by an earlier operation. The new image carries

```text
J = { (x,y) | x ∈ F and (x,y) ∈ R }.
```

It retains the actual borrowed source return and producing receiver, the joint affine carrier,
its supported source and output projections, and the constraint/residual chart. An empty or
partly supported domain is explicit. A particular solution is a coordinate origin for a family,
not a selected actual source or an averaged output.

[proved-derived] Let P be the quotient projection modulo R supplied by the existing exact row
calculus. Define L(u,y)=P(u,y) on U × W. Then

```text
(a+u,y) ∈ R  iff  L(u,y) = -P(a,0).
```

The kernel builds the graph of L from the source-family directions and the output-coordinate
basis, slices it at this actual residual, and translates the source by a. Thus the construction
returns exactly J in the admitted rational chart. Integer denominator clearing changes the
presentation, not that relation. Native overflow remains a refusal, not an unrecorded rounding.

[proved-derived] The projected supported source B is an affine subset of F. Full coverage is
equivalent to a ∈ B and U contained in the direction space of B. Testing the actual origin and a
basis of U either establishes that inclusion or supplies a separating member. A unique output
can therefore coexist with a plural input. Conversely, a unique output on B strictly smaller
than F is not an unqualified response for the whole supplied family.

[proved-derived] An actual later observation z restricts the same joint relation to
`{x | (x,z) ∈ J}`. The existing homogenized receive construction pins the affine-origin
coefficient to one before solving; it retains remaining free source directions. This is a
returned condition constraint, not a new row secretly inserted into the learned generator.
